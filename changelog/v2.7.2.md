# V2.7.2（main 分支最新）

更新日期：2026 年 8 月 10 日

## 学校图标与 PDF

- 学校信息新增学校图标上传：自动裁剪为正方形并压缩至 256×256，兼容未设置图标的旧数据。
- 考试页顶部与首页学校信息左侧显示学校图标；未上传时显示默认 Novora 图标。
- A4 PDF 顶部显示学校图标（未上传时显示默认 Novora 图标）；底部左侧在“Novora · 考试管理与教室大屏”前加入品牌图标并对齐。

## 邮箱验证码登录

- 新增邮箱验证码登录：已有管理员可通过“邮箱 + 6 位验证码”登录，不自动创建账号。
- SMTP 在系统内配置（支持 QQ、163 等预设与自定义邮件服务器），授权码加密存储，部署不新增环境变量。
- 绑定邮箱在首次初始化或系统设置中完成；发送验证码带 60 秒间隔与 IP 限频，验证码 5 分钟有效、一次性使用，连续错误锁定 15 分钟。
- 邮件发送走限速队列，失败自动重试退避；邮箱解绑与清空使用内联确认对话框。
- 健康检查、系统状态与邮件发送合并为单个 Serverless 函数，保持在 Vercel 免费版 12 个函数限制内。

## 系统状态

- 新增系统健康检查接口与超级管理员系统状态面板。
- 系统状态展示内存、CPU、系统负载、启动时间，以及数据库版本、大小、表/索引数、连接数、缓存命中率、事务统计等。
- 系统设置按分区分组，带锚点导航与可折叠低频卡片；移动端修复横向溢出，桌面端标题栏保持固定。
- 本地设置页新增“关于”分区。

## 用户与权限

- 内置只读角色更名为“巡考员”，并扩展大型考试、周测、设备、提醒、设置等查看类权限。
- 用户与权限页按角色分组折叠，支持搜索筛选与角色权限矩阵。
- 修复用户行“⋯”菜单层级与点击被遮罩拦截的问题。

## 主题与视觉

- 新增多套后台主题：命令中心（深/浅）、Swiss 极简（Novora 蓝）、深色强化主题，数据屏与各模块页面同步重排。
- 新增吉祥物：登录页右上角按页面轮换，空状态、关于页全部补齐。
- 加载页重设计为教室座位矩阵动画。
- 批量预设支持科目多选与时间选择器，数据屏展示在线设备，支持自定义科目名。

## 本地/内网部署

- 支持纯本地/内网部署：新增 server 适配器复用全部 API，不依赖 Vercel 与 Neon。
- Docker Compose 一键启动（应用 + 内嵌 PostgreSQL 16），数据持久化在 Docker 卷。
- 无 Docker 环境可使用 Node.js 22+ 与本机 PostgreSQL 运行。
- 新增一键更新脚本（npm run update:local / update-local.bat / update-local.sh）。
- 本地与云端部署共用同一份代码，互不冲突。

## 稳定性与修复

- 作用域考试保存改为权威快照合并，修复陈旧数据导致的 403。
- 初始化向导阻止非法输入继续下一步并内联报错。
- 临时考试“立即开始”默认 +1 分钟，并明确过去时间错误提示。
- 云端写入队列进度提示、设备与考试写入统一入队；移动端提示气泡限制在视口内。
- 运行模式与周测冲突策略仅超级管理员可见。
