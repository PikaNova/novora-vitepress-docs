# V2.7.3（main 分支最新）

更新日期：2026 年 8 月 22 日

## 新功能

### 班级访客

- 登录页新增“使用班级访客身份查看”：未绑定设备可直接以访客身份进入，查看权限与原巡考员一致。
- 内置角色“巡考员”更名为“班级访客”；访客令牌按设备绑定班级签发、长期有效，设备解绑或撤销后立即失效。
- 系统设置按权限隐藏不可更改的板块；班级访客隐藏“系统设置”入口，并提供空态兜底。

### SEO 与站点信息

- 初始化向导第 1 步新增学校图标上传与站点信息（浏览器标题后缀、SEO 描述、关键词、站点公开地址），系统设置“学校信息”内可随时修改。
- 浏览器标题显示为“校名 · 页面名”，首页与登录页显示校名。
- 自托管/本地部署时服务端自动注入 title、description、og 与 canonical，并生成 robots.txt 与 sitemap.xml；搜索结果图标保持 Novora 图标。

### 初始化流程

- 初始化向导新增“分科模式”选择器（默认关闭，新部署生效）；现有部署仍可在系统设置中修改。
- 使用文档支持页内嵌预览与阅读确认，可勾选确认，也可跳过。

### 批量预设

- 科目组与时间组统一写入学校云端数据库，取消“本机预设”；旧本机数据会弹出确认框，按名称去重导入后清空本地。

### 系统状态

- 系统状态面板默认折叠（折叠时暂停轮询），精简显示项（概览 4 卡 + 服务/数据库/邮件队列核心 + 最近事件 5 条），展开时 10 秒实时刷新，状态点带动态脉冲动画，并修复手机端溢出。

### 部署与更新

- Dockerfile 统一 Node 24；npm ci 固化国内镜像源（默认 registry.npmmirror.com，含重试）。
- 本地/内网部署接入标准 pg 驱动直连 PostgreSQL，Neon 云端路径不变。
- 更新检查改为 GitHub 优先（8 秒超时）→ 作者端回退；版本与更新界面按部署平台显示（Vercel 步骤 / 本地一键复制命令）。
- 维护文档统一指向 docs.pikachu2026.space，界面不再跳转 GitHub。

### 导入入口

- 大型考试页新增“AI智能导入考试”（从“我的账户”菜单移出），周测入口更名为“AI智能导入周测”。

## Bug 修复

- 修复仪表盘手机端详情抽屉不显示的问题：改用 Portal 渲染到 document.body，并增加 100vh 高度兜底，避免“只有遮罩、面板不出现”。
- 修复首次登录改密流程中绑定邮箱被 403 拦截的问题。
- 同步 package-lock.json 与 package.json 依赖（补齐 nodemailer、pg）。
- 更新 Docker 部署文档与国内访问相关说明。
