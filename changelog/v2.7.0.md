# V2.7.0

- 新增客户端错误上报：全局 window.onerror / unhandledrejection、React 顶层错误边界、影响服务稳定性的 API 错误，在用户同意遥测后静默上报。
- 新增 /api/error-report 同源中转函数，浏览器不接触作者端密钥；部署者无需新增环境变量，作者端不可用时自动跳过。
- 遥测与错误上报支持公开配置包控制开关、采样率、禁用版本、备用域名和最大 stack 长度。
- 错误上报过滤密码、恢复密钥、Token、Cookie 等敏感字段，并对同一分钟内相同错误指纹去重。
- 页面渲染异常时显示可恢复的刷新提示，避免白屏。
- 保留并合并超级管理员修复/重建入口及初始化向导复选框样式修复。
