# V2.8.0（当前版本）

更新日期：2026 年 9 月

本版把 Novora 从「能发布考试的大屏工具」升级为「基础考试管理系统」：考试有了独立记录、生命周期和操作历史，系统有了诊断日志与错误上报，管理后台与系统设置的界面也重新组织。

::: tip 升级影响
旧客户端的读取契约不变。教室大屏、ClassIsland 插件和已有考试数据不需要做额外操作，直接升级即可。
:::

## 新功能

### 考试记录管理

- 新增考试记录：每场考试都有独立记录，包含名称、备注、状态、适用年级与班级、来源、创建人和创建时间。
- 考试列表支持按**状态、年级/班级、来源、时间范围、创建人**筛选，支持关键词搜索与分页，并按账号数据范围自动过滤。
- 状态分为**草稿、待开始、进行中、已结束、历史归档**；其中「待开始 / 进行中」按考试时间窗与暂停时长自动推导，不需要人工维护。
- 新增考试详情，展示**生命周期时间线、累计暂停时长和完整操作记录**（谁在什么时候做了什么）。
- 新增生命周期操作：**发布、开考、暂停、继续、延长、结束、归档、反归档、复制**。
  - 暂停时长不计入实际用时，继续时自动结算；
  - 延长会顺延结束时间，重复提交不会重复加时；
  - 复制一场考试不会产生重复记录；
  - 非法的状态跳转会被拒绝并给出提示。
- 所有状态变更都会记录操作人，可在操作记录中追溯。
- 归档的考试从默认列表隐藏，但仍保留历史，可以随时反归档。

### 诊断日志与错误上报

- 系统设置新增**诊断日志**面板，可配置：
  - 错误发生时保留前后日志的时间范围；
  - 日志保留天数（1–30 天），超期自动清除；
  - 管理员手动上传日志包给作者端。
- 日志默认只留在这台设备上，**不会自动外发**；只有管理员主动上传后才会发送。
- 已打开遥测时，客户端会静默上报影响稳定性的错误（接口 5xx、数据库读写失败、页面渲染异常、分包加载失败等）。
- 上报内容经过脱敏：不包含考试安排正文、管理员密码、恢复密钥和登录会话；权限不足、登录过期、密码错误等正常业务提示不会被当作系统错误上报。
- 作者端不可用时自动跳过，不影响正常使用。

### 界面重组

- **系统设置**改为左侧分组导航 + 分组视图，桌面端不再显示冗余分组胶囊；新增「诊断日志」与「学校信息」两个独立分组。
- **管理后台**导航改为左侧边栏，页面级筛选与操作按钮集中到顶部上下文栏；页面滚动时导航保持贴边，不再被内容顶开。
- **运行总览**重做呈现：核心状态卡片、运行健康区和常用待办入口，健康状态按设备心跳、考试排期、数据同步分别展示。
- **诊断日志**表单统一使用共享表单控件，操作方式与其他设置项一致。

### 考试大屏

- 大屏无操作 1 分钟后给出「建议全屏」提示条，点击即可进入全屏，不再强行自动进入。
- 考试结束后 15 分钟内提供退出全屏入口和操作指引浮层，方便监考老师离场操作。

### 设备管理

- 设备命令的领取、确认、失败与回执状态会持久保存，管理端可以查看命令的执行情况。

### 部署与工程

- 新增 Docker 镜像构建工作流。
- Dockerfile 统一使用 Node 24，依赖安装固化国内镜像源并带重试。
- 新增数据库结构版本门禁与独立集成测试环境，空库可重复初始化，健康检查会报告结构版本。

## Bug 修复

- 修复 Docker 容器端口问题：容器内固定监听 3000，宿主机端口映射不再错位。
- 修复诊断日志鉴权：管理端请求正确携带凭据，不再因鉴权失败读不到日志。
- 修复诊断日志保留策略未生效：过期日志包会按设置的天数真正清理，不再长期占用空间。
- 修复旧考试记录字段缺失：缺少的临时考试、优先于课表等标志会被补上默认值，旧数据不再出现空值状态。
- 修复运行总览的健康状态语义：设备心跳、考试排期等维度分别判断，不再笼统显示为异常。
- 修复管理后台侧栏滚动边界：页面滚动时导航栏保持贴边，不再出现断层。
- 修复桌面端设置分组胶囊重复显示的问题。
- 修复学校预设同步和响应式标题的显示问题。
- 修复初始化向导文档内嵌预览的问题，改为外部链接打开。
- 修复首次登录改密流程中绑定邮箱被拒绝的问题。
- 修复仪表盘手机端详情抽屉不显示的问题。
- 修复多个页面的状态更新与清理问题，回调始终读取最新状态，定时器正确释放。
- 修复无名称的历史年级和班级在同步后丢失的问题。

## 性能优化

- 考试列表的筛选与分页下推到数据库执行，记录较多时不再整表读取。
- 精简心跳、状态与鉴权请求的往返次数，减少免费额度下的数据库压力。
- 版本化快照地址由服务端能力控制，不再无故失效公告缓存。

## 升级提示

1. 升级前备份数据库；
2. 云端部署先同步 Fork，本地部署先 `git pull`；
3. 升级后确认版本号已变化，并完成一次核心验收（登录、后台保存、大屏、PDF）；
4. 教室大屏和 ClassIsland 插件无需额外操作。
