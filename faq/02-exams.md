# 考试与周测

## 修改已发布的考试

可以直接改。在「大型考试」中选中该考试，再编辑对应分科目的起止时间或启用状态，保存后大屏会在下一次同步时更新。

V2.8.0 起，考试记录还支持在考试进行中暂停、继续和延长：

| 操作 | 适用状态 | 说明 |
| --- | --- | --- |
| 开考 | 已发布、未开考 | 记录实际开始时间 |
| 暂停 | 已发布、已开考 | 记录暂停时刻，暂停时长不计入实际用时 |
| 继续 | 暂停中 | 结算暂停时长 |
| 延长 | 已发布 | 顺延结束时间，需提供幂等键防重复提交 |
| 结束 | 已发布或草稿 | 记录实际结束时间 |

每次操作都会写入操作记录，包含操作人、原始状态和目标状态，可在考试详情中查看。

## 只有一部分年级要考，怎么设置

新建或编辑考试时在「适用范围」选择全校或指定年级。同一时间存在不同范围的考试时，调度按更具体的范围优先：

```text
班级范围 > 年级范围 > 全校范围
```

普通年级考试不要误选「全校」，否则所有绑定年级的设备都会匹配到它。

## 周测不显示

按顺序检查：

1. **计划是否启用**——停用的计划不会生成实例；
2. **是否在生效期内**——生效开始日期晚于当前日期时不会出现；
3. **周测项是否启用**——单个周测项也可以被停用；
4. **周次是否正确**——A/B 周模式下，「仅 A 周」的项目在 B 周不会出现；
5. **是否被大型考试暂停**——自动运行模式下按冲突策略暂停；
6. **预览的周次是否是目标周**——日历默认从当前周开始。

## A/B 周对不上

A/B 周由「学期开始日期 + 周次模式」共同决定。如果单双周与学校实际不符，优先检查学期开始日期是否填写正确，而不是逐个修改周测项。

修改学期开始日期会影响所有周测的周次计算，正式学期中调整前应先确认影响范围。

## 周测和大型考试冲突了

自动运行模式下，大型考试按策略暂停周测，三种范围可选：

| 策略 | 行为 |
| --- | --- |
| 时间重叠 | 只暂停与大型考试实际重叠的周测 |
| 当天 | 大型考试当天不生成周测 |
| 整个考期 | 从第一科开始到最后一科结束期间暂停周测 |

对某一次冲突还可以单独处理：取消本次、临时调整日期时间，或强制本周仍然进行。单次调整不会修改周期规则本身，需要恢复时在例外日期管理中撤销。

## 只是想隐藏某一科，需要删除吗

不需要。关闭该分科目的「启用此科目」即可，它不会显示在大屏和 PDF 上，但数据仍然保留，之后可以重新启用。

## JSON 导入失败

常见原因：

- 文件不是合法 JSON（多余逗号、中文引号、缺引号）；
- 字段名与要求不一致，例如把 `startTime` 写成 `start_time`；
- 时间格式不对，应为 `2026-09-07T08:30:00`；
- 粘贴时带入了 AI 输出的解释文字或 Markdown 代码块标记。

导入前界面会校验字段并按开始时间排序。使用 AI 智能导入时，只把生成的提示词交给 AI，再把 AI 返回的**纯 JSON** 粘贴回来。Novora 不会自动上传考试照片。

旧版 `items` 格式会覆盖当前周测列表；新版完整计划备份会创建独立计划并保留 A/B 周、例外和节假日设置。导入前确认用的是哪一种。

## 一次给多个班级建周测

在新建计划时用班级选择器一次勾选多个班级，系统会为每个班级创建一份**独立**计划。之后修改其中一个班级，不会联动修改其他副本。

已有标准计划时，也可以用「批量应用」或「同步至同年级其他班级」，效果相同。

## 考试时间重叠会怎样

保存分科目时，如果与已有启用科目的时间重叠，系统会要求再次确认。先判断是不是日期或上午/下午填错；只有确实允许并行安排时才继续。

考试持续超过 6 小时时，必须勾选确认这是跨天或特殊考试。普通两小时考试触发该提示，通常意味着结束日期填错。
