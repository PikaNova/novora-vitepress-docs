## 名词看不懂

先查[术语表](/start/04-glossary)，覆盖考试调度、账号权限、设备、部署和数据诊断五类术语。

## 报错了

1. 在[错误信息对照表](/appendix/f-error-reference)里找错误标识或 HTTP 状态码；
2. 按提示处理；
3. 没找到就进[故障排查](/appendix/a-troubleshooting)按现象对照；
4. 仍然不行，带请求 ID 到官方交流群 `1067566386` 提问。

## 没有找到答案

1. 先看[故障排查](/appendix/a-troubleshooting)的现象对照表；
2. 再查[更新日志](/changelog)确认是不是新版本改动的行为；
3. 仍未解决时，带着请求 ID、Novora 版本和操作步骤到官方交流群 `1067566386` 提问。

::: warning 提问时不要发送的内容
数据库连接串、管理员密码、Deploy Hook URL、恢复密钥、完整请求头。这些都属于凭据，一旦发出就应视为已泄露并立即轮换。
:::
