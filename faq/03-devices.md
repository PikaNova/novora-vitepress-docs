# 设备与大屏

## 大屏不更新

按顺序排查：

1. 在那台设备上打开首页，确认页面能正常加载；
2. 访问 `/api/time`，确认返回 JSON 而不是错误页；
3. 在「设备管理」中确认该设备显示为在线；
4. 确认绑定的年级和班级与实际教室一致；
5. 确认考试确实适用于这个班级；
6. 强制刷新页面，或等待下一次同步。

设备超过 90 秒没有上报心跳时，不再显示为「正在考试」。设备实际开机却显示离线，通常是浏览器休眠、系统冻结或网络中断。

## 一台设备应该绑定几个班级

一台设备只绑定一个班级。首页或本地设置中的班级选择器用于选择年级和班级，选完后该设备只显示这个班级的周测和适用于它的大型考试。

绑定关系保存在云端，清除浏览器缓存会丢失本机选择，需要重新选一次。

## 换教室或班级调整了怎么办

1. 在大屏设备上打开首页；
2. 用班级选择器重新选择新的年级和班级；
3. 回到后台「设备管理」确认绑定已更新；
4. 在大屏上确认显示的考试范围正确。

如果是整年级调整（例如升高一变成高二），先在「年级与班级」中维护结构，再逐台设备重新绑定。只有名称变化时应使用重命名，不要删除后重建——删除会产生新的内部 ID，原设备绑定、周测计划和权限不会自动跟随。

## 怎么知道哪台设备是哪台

「设备管理」中每台设备都有实例 ID。同一班级有多台设备时，应按实例 ID 区分，而不是只看设备名称。

建议在部署时给每台设备做个物理标记（贴纸写实例 ID 后四位），排查时不用来回确认。

## ClassIsland 插件配对失败

常见原因：

| 现象 | 检查 |
| --- | --- |
| 配对令牌无效或过期 | 令牌有效期 5 分钟，重新发起配对 |
| 浏览器打开配对页后没有班级 | 确认已经创建年级和班级 |
| 配对完成但插件不显示考试 | 确认设备绑定的班级有适用的考试安排 |
| 后台看不到插件设备 | 配对成功后网页看板与插件会合并显示为同一台设备，刷新设备管理 |

详细步骤见[ClassIsland 配对与设备绑定](/integrations/classisland/02-pairing)。

## 解除绑定会发生什么

- 当前网页看板失去云端班级绑定，需要回到首页重新选择；
- 关联的 ClassIsland 凭据被撤销，需要重新配对；
- 原始客户端密钥不会被接口再次返回。

删除或解绑不是「隐藏记录」，而是撤销设备访问关系。批量操作前先缩小筛选范围并核对已选数量。

## 临时考试会不会影响其他教室

不会。快速开始考试创建的是当前设备的本地临时考试，只在这台设备上显示。它适合课堂随测，不应代替全校正式大型考试。

需要设置是否让它覆盖当前正式安排。设备管理里也可以远程查看和管理各设备的临时考试。

## 大屏应该怎么设置

建议：

- 用全屏模式展示；大屏无操作 1 分钟后会出现「建议全屏」提示条，点一次即可进入全屏；
- 不要在教室大屏的浏览器里保存管理员密码；
- 收藏正式域名或内网地址，避免每次手动输入；
- 如果教室电脑会关机，开机后让它自动打开大屏地址。

考试结束后 15 分钟内，大屏会弹出退出全屏的入口，方便监考老师离场操作。

## 显示比例或字体不合适

在本地设置中调整大屏设计和字体。设计只影响当前设备外观，不改变云端考试时间。正式使用前建议检查：

- 投影或大屏上的对比度；
- 长科目名称是否完整显示；
- 倒计时是否清晰；
- 夜间教室是否过亮。
