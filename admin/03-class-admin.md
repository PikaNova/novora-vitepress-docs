# 3. 班级管理员

班级管理员管理自己班上的周测和设备，并查看适用于本班的考试安排。这是最贴近日常教学的角色。

## 你能做什么

- 维护本班周测计划与周测项；
- 处理单次取消、临时调课等例外；
- 查看本班设备在线状态和绑定；
- 查看适用于本班的大型考试；
- 设置本机班级和显示偏好；
- 修改自己的用户名和密码。

## 不能做什么

- 创建或修改大型考试（由年级管理员或超级管理员负责）；
- 创建年级或班级；
- 管理其他班级的数据；
- 创建或管理用户账号。

## 首次登录要做的

班级管理员账号通常由年级管理员批量创建。首次登录时系统要求设置自己的新用户名和新密码，两项凭据一次性原子保存，成功后旧会话立即失效。请把新凭据保存到可信位置。

## 开学第一周要做完的事

- [ ] 确认本班周测计划的生效日期已更新到新学期；
- [ ] 核对周三、周五等周测项的星期和时间；
- [ ] 确认 A/B 周设置与班级课表一致；
- [ ] 检查本班大屏设备是否在线、绑定班级是否正确；
- [ ] 在日历中逐周确认未来两周的周测都已经正确出现；
- [ ] 确认没有与年级大型考试冲突的安排。

## 维护本班周测

### 新增一项周测

1. 进入「周测计划」，选择本班；
2. 点击「+ 添加周测」；
3. 填写名称、星期、开始与结束时间；
4. A/B 周模式需要选择「都进行 / 仅 A 周 / 仅 B 周」；
5. 结束时间落在第二天时勾选「跨日结束」；
6. 保存后到日历确认实例出现。

### 临时取消或调课

在日历中点击目标周测实例，选择取消本次或临时调整。**单次调整不会改变周期规则**，下周仍按原规则执行；需要恢复时在例外日期管理中撤销。

### 大型考试期间本班周测被暂停

这是自动运行模式的正常行为，按年级管理员配置的冲突策略执行。如果确实需要本周照常进行，可以在实例上选择强制本周仍然进行。

## 检查本班大屏

每次考试前建议：

1. 打开大屏确认显示的是本班班级；
2. 确认下一场考试的名称、科目和倒计时正确；
3. 确认全屏显示正常；
4. 发现异常时先刷新，再到首页确认班级绑定。

考试结束后 15 分钟内，大屏会提示退出全屏，方便监考老师操作。

## 修改自己的账号

「更多 → 我的账户」可以修改用户名和密码。忘记密码时联系所属年级管理员或超级管理员重置，重置后会拿到一个只显示一次的临时密码，下次登录需要重新设置。

## 常见问题

**为什么看不到大型考试模块的编辑按钮？** 班级管理员对大型考试只有查看权限，编辑由年级管理员负责。

**修改了本班周测，其他班为什么没变？** 每个班级的计划是独立副本，这是设计行为。需要统一修改时联系年级管理员用批量应用下发。

**日历里某一周没有周测？** 检查是否落在计划的生效期内、是否为 B 周、是否被法定节假日排除，或被大型考试冲突策略暂停。
