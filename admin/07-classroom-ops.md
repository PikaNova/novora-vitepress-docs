# 教室设备日常运维

教室设备是整个系统里最容易出状况的一环：会被断电、被挪动、被换电脑。这篇把常见运维场景做成操作清单。

## 日常巡检（每次考试前）

- [ ] 在运维总览确认本年级设备在线数量
- [ ] 抽查几台设备的绑定班级是否正确
- [ ] 确认大屏显示的是本班而不是别的班
- [ ] 确认倒计时和下一场考试的科目正确
- [ ] 发现长期离线的设备，记录实例 ID 去现场处理

## 教室新装一台大屏

1. 在教室电脑上打开 Novora 地址；
2. 首页选择这台设备实际所属的年级和班级；
3. 进入考试大屏，静置 1 分钟后点「建议全屏」进入全屏；
4. 回后台「设备管理」确认设备已出现并在线；
5. 给设备做个物理标记（实例 ID 后四位）；
6. 建议把大屏地址设为开机自动打开的页面。

## 换教室电脑

1. 旧电脑：后台「设备管理」解除绑定（避免残留一台长期离线设备）；
2. 新电脑：打开地址，重新选择班级；
3. 如果新电脑装了 ClassIsland 插件，重新配对一次；
4. 后台确认新设备在线、绑定正确。

## 设备搬到别的教室

1. 后台解除旧绑定；
2. 在新教室的设备上重新选择新的年级和班级；
3. 插件重新配对；
4. 在大屏上确认显示范围已经变成新班级。

只改插件里的地址是不行的——绑定关系在服务端。

## 学校改造 / 加教室

1. 先在「年级与班级」中创建新班级；
2. 如果需要，用「批量应用」把标准周测复制到新班；
3. 新教室设备按上面的步骤绑定；
4. 需要的话为新班创建班级管理员账号。

## 老设备退役

1. 后台「设备管理」解除绑定；
2. 确认这台设备的临时考试不再需要；
3. 把物理标记一并移除，避免以后混淆；
4. 如果是批量退役，先用筛选缩小范围并核对数量，再批量解绑。

## 断网与断电恢复

| 情况 | 表现 | 处理 |
| --- | --- | --- |
| 教室断电 | 大屏黑屏 | 恢复供电后设备重新打开地址并进全屏 |
| 网络中断 | 大屏显示旧数据 | 恢复后自动同步；期间不影响已发布的考试显示 |
| 浏览器被关闭 | 大屏不显示 | 重开地址；建议设置开机自启 |
| 系统自动更新 | 浏览器短暂重启 | 更新完成后重新打开大屏地址 |

## 大屏显示不正常的排查顺序

1. 刷新页面；
2. 回首页确认班级绑定还在；
3. 访问 `/api/time` 确认能连上服务端；
4. 换一台设备试同一地址，判断是设备问题还是服务问题；
5. 仍然异常时记录请求 ID，查[错误信息对照表](/appendix/f-error-reference)。

## 建议固定下来的三件事

1. **谁负责**：指定一名电教老师负责教室设备，班级管理员负责本班确认；
2. **多久巡检**：至少每次考试前检查一次；
3. **怎么上报**：发现异常统一带上实例 ID 和 Request ID 反馈，不要只在群里说"大屏坏了"。
