# 2. 年级管理员

年级管理员负责授权年级内的考试、周测、班级、设备和下级用户（班级管理员）。

## 你能做什么

- 维护本年级的班级；
- 发布和编辑本年级的大型考试；
- 维护本年级各班的周测计划；
- 查看和管理本年级设备；
- 批量创建本班对应的班级管理员账号；
- 重置本年级班级管理员的密码。

## 不能做什么

- 创建或删除年级（只有超级管理员可以）；
- 管理其他年级的数据；
- 修改角色定义和系统设置。

## 发布一次年级考试的标准流程

1. **确认范围**——在大型考试中把「适用范围」选为你的年级，不要误选「全校」；
2. **创建容器**——先建考试名称，例如「高二期中」；
3. **逐科添加**——填写每科开始和结束时间；
4. **检查重叠**——时间重叠会要求二次确认，先确认不是日期填错；
5. **预览 PDF**——确认校名、年级、考试名和各科时间；
6. **目标班级验收**——用一台测试设备选一个本年级班级，确认大屏显示正确；
7. **非目标班级反向验证**——切到一个非本年级班级，确认不会误显示；
8. **通知班级管理员**——告知考试时间和需要检查的设备。

## 一场考试进行中的操作

考试当天可能需要临时调整。V2.8.0 起，考试记录提供开考、暂停、继续、延长和结束五个操作：

| 操作 | 效果 |
| --- | --- |
| 开考 | 记录实际开始时间 |
| 暂停 | 暂停时长不计入实际用时 |
| 继续 | 结算本轮暂停时长 |
| 延长 | 顺延结束时间 |
| 结束 | 记录实际结束时间 |

每次操作都会记录操作人。考试结束后可以把记录归档，归档不影响历史查看，但不再出现在默认列表里。

## 管理本年级设备

建议在每次考试前检查：

- 本年级各班的设备是否都在线；
- 绑定班级是否与实际教室一致；
- 是否有设备长期离线需要现场处理。

超过 90 秒没有心跳的设备不会显示为在线。设备实际开机却离线时，让现场老师打开首页确认网络。

## 创建班级管理员

用「批量添加班级管理员」可以一班一账号：

1. 设置用户名统一前缀；
2. 设置初始密码；
3. 用班级选择器勾选目标班级；
4. 确认创建数量；
5. 分别交付账号。

每个账号只获得对应班级作用域。班级管理员首次登录必须同时设置自己的新用户名和新密码。

## 学期初要做的

- [ ] 确认本年级班级结构（新增班级、合并班级、命名调整）
- [ ] 检查各班周测计划的生效日期是否已更新到新学期
- [ ] 确认 A/B 周的起始周次与学校安排一致
- [ ] 逐班确认设备绑定（假期中设备可能被移动）
- [ ] 给新班级创建班级管理员账号
- [ ] 通知班主任或班级管理员确认本班周测

## 学期末要做的

- [ ] 归档已完成的大型考试
- [ ] 导出需要留存的考试与周测 JSON
- [ ] 停用已不再使用的班级管理员账号
- [ ] 把下学期的年级归属变化反馈给超级管理员

## 常见问题

**为什么看不到某个模块？** 你的角色可能只被授予了部分模块权限，或数据范围不含目标年级。请联系超级管理员调整。

**为什么修改本班周测没有影响其他班？** 批量创建时为每个班级生成了独立计划，这是设计行为。需要全校统一时用「批量应用」重新下发。

**年级名称变了怎么办？** 重命名不影响已有考试和设备绑定；但用「删除后重建」会产生新的内部 ID，原绑定不会自动跟随。
