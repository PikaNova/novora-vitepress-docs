# 5. 学期切换清单

每学期开学和结束都有一批固定操作。这份清单按时间顺序整理，可以打印出来按项打勾。

## 开学前两周

### 超级管理员

- [ ] 在系统设置中更新**学期开始日期**（决定周次与 A/B 周计算）
- [ ] 确认周次模式：统一周表还是 A/B 周交替
- [ ] 确认法定节假日排除规则
- [ ] 确认默认运行模式：仅大型考试 / 仅周测 / 自动调度
- [ ] 更新年级与班级结构：新高一建立、毕业年级归档
- [ ] 复核各年级管理员的授权范围
- [ ] 检查系统版本是否为当前稳定版，必要时安排更新
- [ ] 完成一次数据库备份与恢复演练
- [ ] 确认恢复密钥仍可取用

### 年级管理员

- [ ] 确认本年级班级列表（新增、合并、改名）
- [ ] 检查各班周测计划的生效日期是否已更新
- [ ] 确认 A/B 周的起始周次与学校安排一致
- [ ] 为新建班级创建班级管理员账号
- [ ] 通知班级管理员核对自己班级的周测

### 班级管理员

- [ ] 核对本班周测项的星期和时间
- [ ] 在日历中逐周确认未来两周安排正确
- [ ] 确认本班大屏在线并绑定正确班级

## 开学第一周

- [ ] 逐台教室大屏现场确认显示正常
- [ ] 确认大屏绑定的是实际教室对应的班级
- [ ] 用一台测试设备完整走一遍验收：登录、保存、大屏、PDF
- [ ] 确认 ClassIsland 插件同步正常（如启用）
- [ ] 收集并处理老师反馈的问题

## 每次考试前

- [ ] 确认考试的适用范围和每个科目的起止时间
- [ ] 确认没有误选「全校」的年级考试
- [ ] 检查是否存在时间重叠冲突
- [ ] 生成并检查 A4 PDF
- [ ] 在目标班级设备上确认显示正确
- [ ] 在非目标班级设备上确认不会误显示
- [ ] 确认相关教室的大屏都在线

## 考试进行中

- [ ] 需要时使用暂停、继续、延长；提前收场用「申请停止」，异常时用「强制结束」，并说明原因
- [ ] 关注运行总览中的设备在线状态
- [ ] 出现大屏异常先刷新，再确认班级绑定

## 考试结束后

- [ ] 确认系统已判定结束（或已用强制结束），结束时间记录正确
- [ ] 把已完成的大型考试归档
- [ ] 检查考试记录中的操作记录是否完整
- [ ] 处理老师反馈的显示问题

## 学期末

### 超级管理员

- [ ] 归档本学期大型考试
- [ ] 导出需要长期保存的考试与周测 JSON
- [ ] 完成一次离线备份并归档
- [ ] 检查审计日志中的异常操作
- [ ] 停用已离职人员的账号
- [ ] 评估是否需要升级版本到下一学年推荐版本

### 年级管理员

- [ ] 归档本年级已完成考试
- [ ] 汇总下学期的年级归属变化，反馈给超级管理员
- [ ] 停用不再使用的班级管理员账号

### 班级管理员

- [ ] 停用或清理本班不再需要的周测
- [ ] 记录假期中设备的去向（是否会被移动或收存）

## 假期中

- [ ] 确认服务器或 Vercel 项目在假期期间保持可用
- [ ] 确认域名、证书、数据库不会因欠费或闲置被回收
- [ ] 本地部署确认设备在断电恢复后能自动拉起
- [ ] 需要断电的教室设备记录好重启后的操作步骤
