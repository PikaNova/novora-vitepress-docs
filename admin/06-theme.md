# 外观、主题与品牌

Novora 的外观分两层：**后台外观**影响管理员看到的管理界面，**大屏外观**影响教室投影的内容。两层互不影响，不要指望在后台换主题会改变教室大屏。

## 后台主题

V2.7 起，后台提供多套主题，可在系统设置中切换：

| 主题 | 适合 |
| --- | --- |
| 命令中心 | 信息密度较高，适合经常盯总览的管理员 |
| Swiss 极简 | 界面干净，适合投影演示或远程协助 |
| 深色强化 | 光线较暗的办公室 |

切换主题只影响当前浏览器的显示，不改变数据，也不影响其他管理员。

同一分组里还有吉祥物展示开关，属于装饰项，可以按学校风格决定是否开启。

## 大屏设计与字体

教室大屏的外观在**本机设置**里配置，不在后台：

| 项目 | 位置 | 影响范围 |
| --- | --- | --- |
| 大屏设计（多套风格） | 本地设置 | 仅当前设备 |
| 标题、正文、时间数字字体 | 本地设置 | 仅当前设备 |
| 动效与显示偏好 | 本地设置 | 仅当前设备 |

大屏提供多种亮色、深色、黑板风格，正式使用前建议检查：

- 投影或大屏上的对比度；
- 长科目名称是否完整显示；
- 倒计时是否清晰可辨；
- 夜间教室是否过亮。

## 学校图标与站点信息

在系统设置「学校信息」分组中维护：

| 项目 | 说明 |
| --- | --- |
| 学校图标 | 自动裁剪为正方形并压缩至 256×256 |
| 学校名称 | 显示在首页、预览和 PDF 中 |
| 浏览器标题后缀 | 浏览器标签显示的校名或简称 |
| 站点描述、关键词、公开地址 | 用于搜索结果与分享卡片 |

图标会显示在：

- 考试页顶部；
- 首页学校信息左侧；
- A4 PDF 顶部。

未上传图标时显示默认 Novora 图标，旧数据不需要手工迁移。

## 浏览器标题与 SEO

浏览器标题显示为「校名 · 页面名」。自托管和本地部署时，服务端会自动注入 title、description、og 和 canonical，并生成 `robots.txt` 与 `sitemap.xml`。

搜索结果中的图标保持 Novora 图标，不随学校图标变化。

## 初始化向导里的外观设置

初始化第 1 步就包含学校图标上传和站点信息。当时跳过的项目，之后都可以在系统设置 → 学校信息里补。

## 打印与 PDF 的品牌信息

PDF 底部左侧为「Novora · 考试管理与教室大屏」品牌区，右侧为「Made by PikaNova」，与学校图标一起构成页脚。
