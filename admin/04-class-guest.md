# 4. 班级访客

班级访客（原「巡考员」）是只读角色，用于巡考、教务查看和临时监督。它不需要编辑权限，也就不容易误改数据。

## 你能看到什么

按授权范围只读查看：

- 大型考试安排与状态；
- 周测计划与日历；
- 设备在线状态与绑定；
- 提醒设置；
- 系统设置中的只读内容。

同时支持把安排导出为 A4 PDF。

## 你不能做什么

- 修改或删除任何考试、周测、班级、设备；
- 创建用户或修改权限；
- 进入部署、数据维护和版本更新相关的操作。

界面会按权限隐藏不可更改的板块。系统设置入口对班级访客不可见，直接访问会得到空态页面。

## 怎么进入

两种方式：

1. **班级访客账号**——由超级管理员或年级管理员创建，分配只读角色和班级范围；
2. **班级访客身份查看**——登录页提供「使用班级访客身份查看」入口，未绑定设备也可以直接以访客身份进入。

第二种方式适合临时设备或外来巡考人员：查看权限与正式账号一致，但不涉及账号管理。

## 授权范围和设备绑定

访客的可见范围由管理员在创建账号时指定（全校、年级或班级）。如果看到的范围不对，联系管理员调整，不要尝试通过修改页面地址绕过——服务端会重新校验。

使用「班级访客身份查看」进入时，访问令牌按设备绑定的班级签发，设备解绑或撤销后立即失效。

## 巡考时的建议用法

- 用安排预览查看本班当日和次日考试；
- 需要纸质版时直接下载 A4 PDF；
- 发现大屏显示异常时，记录设备实例 ID 和班级，反馈给年级管理员；
- 不要用访客账号在大屏设备上保存密码。

## 常见问题

**为什么系统设置是空的？** 这是设计行为，班级访客没有修改系统设置的权限，因此该入口被隐藏。

**能帮别人改一场考试吗？** 不能。需要修改时联系负责该年级的年级管理员或超级管理员。

**临时访客需要单独建账号吗？** 不一定。短期巡考可以直接用登录页的班级访客身份进入；需要长期使用、要留审计记录的再建正式账号。
