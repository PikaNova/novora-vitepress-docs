# 模块一：运行总览

运行总览是管理员登录后的系统状态页，用来快速判断设备、考试和数据库是否正常。超级管理员看到全校数据，年级管理员只看到授权范围。

## 四项核心指标

| 指标 | 含义 |
| --- | --- |
| 在线设备 | 最近仍在上报心跳的看板数量，以及其中正在考试的数量 |
| 待执行大型考试 | 管理范围内尚未结束的正式考试数量，同时显示启用的周测计划数 |
| 数据库状态 | 当前读取是否正常，以及管理范围内的年级和班级数量 |
| 需要关注 | 数据库异常或大型考试时间、范围冲突数量 |

设备超过 90 秒未上报时，不再作为“正在考试”显示，避免离线设备长期占用状态。

## 正在进行

“正在进行”区域列出当前正在考试的设备，包括：

- 当前科目；
- 所属考试；
- 绑定班级；
- 设备实例 ID。

实例 ID 用于区分同名或同班设备。排查教室大屏时，应同时核对实例 ID 和班级，而不是只看设备名称。

## 大型考试冲突

当两场大型考试的适用范围和时间重叠时，总览会显示冲突提醒。处理方式：

1. 打开“大型考试”；
2. 选择提示涉及的年级；
3. 切换相关考试；
4. 检查适用范围和各科起止时间；
5. 删除重复考试，或调整时间、范围和启用状态；
6. 返回总览确认冲突消失。

## 如何判断系统正常

- 数据库状态为“连接正常”；
- 同步状态正常，没有持续错误；
- 实际开机的教室设备能显示为在线；
- 当前考试设备的科目和班级正确；
- “需要关注”为 0，或所有提示均已确认；
- 刷新后数据不丢失。

## 适合什么时候查看

- 发布大型考试或周测之后；
- 正式开考前；
- 教室反馈大屏没有更新时；
- Vercel 或 Neon 维护后；
- 执行批量设备解绑、数据库恢复或版本升级后。

运行总览是监控入口，不是编辑页面。发现问题后，应进入对应模块修改。
