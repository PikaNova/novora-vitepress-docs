# 模块一：运行总览

运行总览是管理员登录后的系统状态页，用来快速判断设备、考试和数据库是否正常。超级管理员看到全校数据，年级管理员只看到授权范围。

V2.8.0 重做了总览的呈现方式：顶部是核心状态卡片，中间是运行健康区，底部是常用的待办入口。

## 四项核心指标

| 指标 | 含义 |
| --- | --- |
| 在线设备 | 最近仍在上报心跳的看板数量，以及其中正在考试的数量 |
| 待执行大型考试 | 管理范围内尚未结束的正式考试数量，同时显示启用的周测计划数 |
| 数据库状态 | 当前读取是否正常，以及管理范围内的年级和班级数量 |
| 需要关注 | 数据库异常或大型考试时间、范围冲突数量 |

设备超过 90 秒未上报时，不再作为“正在考试”显示，避免离线设备长期占用状态。

## 运行健康区

健康区把「系统是否正常」拆成几个独立维度，避免一个异常掩盖另一个：

| 维度 | 正常表现 |
| --- | --- |
| 设备心跳 | 显示在线设备数 / 已绑定设备总数，例如 `12/14` |
| 考试排期 | 没有时间或范围冲突 |
| 数据同步 | 最近一次同步成功，没有持续错误 |

某个维度不可用时会单独标注为「状态暂不可用」，而不是笼统显示为异常。

## 正在进行

“正在进行”区域列出当前正在考试的设备，包括：

- 当前科目；
- 所属考试；
- 绑定班级；
- 设备实例 ID。

实例 ID 用于区分同名或同班设备。排查教室大屏时，应同时核对实例 ID 和班级，而不是只看设备名称。

## 大型考试冲突

当两场大型考试的适用范围和时间重叠时，总览会显示冲突提醒。处理方式：

1. 打开“大型考试”；
2. 选择提示涉及的年级；
3. 切换相关考试；
4. 检查适用范围和各科起止时间；
5. 删除重复考试，或调整时间、范围和启用状态；
6. 返回总览确认冲突消失。

## 系统状态面板（超级管理员）

超级管理员可以在“系统设置 → 系统状态”查看服务器与数据库健康情况，用于升级、排障和维护窗口检查：

- 服务状态：内存总量/可用/使用率、CPU 型号/核心数/使用率、系统负载、启动时间；
- 数据库状态：连接是否正常、版本、大小、表与索引数量、连接数、缓存命中率、事务统计；
- 本地/内网部署：额外展示最近 5 分钟请求统计。

面板只读展示，不会修改数据。发现异常时，结合部署环境日志排查，必要时先备份再处理。

## 如何判断系统正常

- 数据库状态为“连接正常”；
- 同步状态正常，没有持续错误；
- 实际开机的教室设备能显示为在线；
- 当前考试设备的科目和班级正确；
- “需要关注”为 0，或所有提示均已确认；
- 刷新后数据不丢失。

## 适合什么时候查看

- 发布大型考试或周测之后；
- 正式开考前；
- 教室反馈大屏没有更新时；
- Vercel 或 Neon 维护后；
- 执行批量设备解绑、数据库恢复或版本升级后。

运行总览是监控入口，不是编辑页面。发现问题后，应进入对应模块修改。
