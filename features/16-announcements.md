# 公告与使用文档

首页和后台的「系统公告」来自作者端，用来发布版本说明、使用文档和临时通知。这篇讲它是怎么同步的，以及看不到时怎么处理。

## 公告从哪来

```text
作者端发布公告 / 文档
      |
      v
客户端请求公告接口
      |
      v
首页「系统公告」与管理后台「更多 -> 查看公告」
```

公告和文档由作者端维护，学校不需要自己配置。文字与图片都通过接口下发。

## 在哪里查看

| 入口 | 位置 |
| --- | --- |
| 首页 | 系统公告 |
| 管理后台 | 更多 → 查看公告 |
| 文档 | 公告中的「文档」标签，或初始化向导里的文档入口 |

初始化向导不再强制阅读文档，可以跳过，之后随时从上面两个入口打开。

## 看不到公告怎么办

| 现象 | 原因与处理 |
| --- | --- |
| 列表为空 | 作者端暂无公告，或网络暂时不可达；稍后再试 |
| 一直转圈 | 浏览器到作者端的网络不通，检查是否为纯内网环境 |
| 点开文档没有反应 | 浏览器拦截了新窗口；允许弹窗，或从公告里复制链接手动打开 |
| 图片显示不出来 | 图片接口不可达；刷新重试，或查看纯文字内容 |

## 纯内网部署的表现

教室完全不能出网时，公告和图片请求会被自动跳过，界面显示空态而不是报错。这不影响排考、大屏、管理后台和 PDF。

需要在内网也能看到公告时，有两种做法：

1. 放通服务器到作者端的出网规则；
2. 自建遥测后台，并用 `TELEMETRY_*` 系列变量覆盖默认地址（见 Vercel 环境变量文档中的「遥测覆盖变量」）。

## 文档和内嵌预览的区别

早期版本的初始化向导会内嵌预览文档页面。现在改为在外部标签页打开，避免内嵌页面在部分浏览器上加载失败。

如果浏览器阻止新窗口，无需修改浏览器权限——直接从「系统公告 → 文档」再打开一次即可。

## 公告和遥测的关系

公告是**下载**内容，遥测是**上传**数据，两者是不同方向：

| 功能 | 方向 | 内容 |
| --- | --- | --- |
| 公告与文档 | 作者端 → 客户端 | 版本说明、使用文档 |
| 遥测 | 客户端 → 作者端 | 版本、运行环境、匿名实例标识、省份、校名 |

遥测不包含考试正文、管理员密码、恢复密钥和登录会话，可以在系统设置中关闭。
