# 创建一场大型考试

下面以“高三一模”为例，创建一场只适用于高三、包含语文和数学两科的正式考试。

## 创建前准备

先确认：

- 已完成学校、年级和班级初始化；
- 当前账号拥有大型考试创建和编辑权限；
- 已确认每科日期、开始时间和结束时间；
- 已确认考试适用于全校还是某个年级；
- 电脑时间和时区正确。

## 第一步：进入大型考试模块

1. 打开 Novora 自定义域名。
2. 点击“登录管理”，或访问 `/login`。
3. 登录后点击顶部 **大型考试**。
4. 在运行模式旁选择要管理的年级，例如“高三”。

如果看不到大型考试模块，说明当前角色没有 `major.read` 权限。年级列表只显示当前账号授权范围。

## 第二步：新建考试

1. 在左侧“大型考试”卡片点击 **+ 新建**。
2. 名称填写：

```text
高三一模
```

3. 在“适用范围”选择 **高三**。
4. 点击确认保存。

适用范围选择“全校”时，所有绑定年级的设备都会匹配该考试。普通年级考试不要误选全校。

此时只创建了考试容器，还没有任何科目和时间。

## 第三步：添加语文分考试

1. 确认当前切换到“高三一模”。
2. 点击左侧 **+ 添加分考试**。
3. 科目名称填写 `语文`。
4. 选择开始日期和时间，例如 `2026-09-07 08:30`。
5. 选择结束日期和时间，例如 `2026-09-07 10:30`。
6. 保持“启用此科目”勾选。
7. 点击 **确认并保存**。

保存后在右侧考试安排列表中应看到语文及其状态。

## 第四步：添加数学分考试

再次点击 **+ 添加分考试**：

```text
科目名称：数学
开始时间：2026-09-07 14:00
结束时间：2026-09-07 16:00
启用：是
```

点击确认保存。其他科目按同样方式逐一添加。

## 时间重叠和长考试

如果新科目与已有启用科目的时间重叠，系统会要求确认。先判断是否输入了错误日期或上午、下午；只有确实允许并行安排时才继续。

考试持续超过 6 小时时，必须勾选确认这是跨天或特殊考试。普通两小时考试触发该提示，通常意味着结束日期填错。

## 第五步：检查顺序和状态

在右侧检查：

- 科目顺序是否符合考试日程；
- 所有正式科目是否已启用；
- 日期是否跨错天；
- 上午、下午是否正确；
- 是否存在无意的时间重叠；
- 已结束、进行中和未开始状态是否合理。

暂不发布的科目可以停用。删除后页面会提供一次立即撤销机会。

## 第六步：预览和导出 PDF

1. 点击 **预览与导出 PDF**。
2. 检查完整校名、年级、考试名称和各科时间。
3. 确认日期分组与顺序正确。
4. 下载 A4 PDF。
5. 打开 PDF 检查中文字体、页边距和页数。

PDF 正确不代表大屏范围一定正确，还需要设备验收。

## 第七步：在目标班级验收

1. 使用一台测试设备打开首页。
2. 选择“高三”和一个实际班级。
3. 进入考试大屏。
4. 确认显示“高三一模”和下一科。
5. 临时把设备切换到非高三班级。
6. 确认不错误显示高三考试。
7. 返回运行总览检查设备状态。

## 修改考试

- 修改名称或适用范围：点击大型考试卡片中的 **设置**；
- 修改科目：点击对应分考试的编辑入口；
- 临时不显示某科：关闭“启用此科目”；
- 删除整场考试：点击 **删除**，确认当前切换的是正确考试；
- 切换另一场考试：使用考试选择器。

## 使用 JSON 导入

科目较多时可使用“更多 → 导入大型考试 JSON”。示例：

```json
{
  "title": "高三一模",
  "items": [
    {
      "name": "语文",
      "startTime": "2026-09-07T08:30:00",
      "endTime": "2026-09-07T10:30:00",
      "enabled": true
    },
    {
      "name": "数学",
      "startTime": "2026-09-07T14:00:00",
      "endTime": "2026-09-07T16:00:00",
      "enabled": true
    }
  ]
}
```

导入前会校验字段并按开始时间排序。导入窗口的 AI 功能只生成识图提示词，不会自动把考试照片上传给 Novora 或作者端。
