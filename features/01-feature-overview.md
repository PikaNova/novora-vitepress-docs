# 功能总览

Novora V2.8.0 不只是考试倒计时页面，它把学校结构、正式考试、周期周测、教室设备、分级管理员和考试记录放在同一套系统中管理。

想先看这一版新加了什么，可以直接看[V2.8.0 新功能速览](/features/00-whats-new)。

![项目介绍图片-1](/pictures/项目介绍图片-1.jpeg)

## 系统由哪些部分组成

| 使用端 | 主要用途 | 典型使用者 |
| --- | --- | --- |
| 首页 | 查看当前状态、选择本机班级、进入各入口 | 教师、学生、设备维护人员 |
| 考试大屏 | 显示考试名称、科目、倒计时和提醒 | 教室大屏 |
| 管理后台 | 维护考试、周测、班级、设备和账号 | 超级、年级、班级管理员 |
| 安排预览 | 查看本班日历并下载 A4 PDF | 教师、教务人员 |
| 本地设置 | 设置本机班级、设计和字体 | 每台教室设备 |
| ClassIsland 插件 | 同步考试并触发开考提醒 | 已使用 ClassIsland 的教室 |

## 管理后台六个模块

![Novora 管理后台六个模块](/admin-modules.png)

| 模块 | 解决的问题 |
| --- | --- |
| [运行总览](/features/02-overview-module) | 哪些设备在线、哪些正在考试、系统是否有异常 |
| [大型考试](/features/03-major-module) | 如何发布一次有明确日期时间的正式考试 |
| [周测计划](/features/04-weekly-module) | 如何按星期、班级和 A/B 周长期重复安排周测 |
| [年级与班级](/features/05-classes-module) | 如何维护全校组织结构和批量班级 |
| [设备管理](/features/06-devices-module) | 哪台看板属于哪个班级、是否在线、如何解除绑定 |
| [用户与权限](/features/07-users-module) | 谁可以看和修改哪些模块、年级与班级 |

V2.8.0 起，管理后台的导航改为**左侧边栏 + 顶部上下文栏**：模块分组固定在左侧，当前页面的筛选项和操作按钮集中在顶部，页面滚动时导航不会被顶开。

管理员只能看到其角色和数据范围允许的模块。菜单隐藏不是唯一保护，服务端还会再次校验每次请求。

## 大型考试和周测有什么区别

| 对比项 | 大型考试 | 周测计划 |
| --- | --- | --- |
| 时间表达 | 每科使用具体日期和起止时间 | 按星期和时间周期重复 |
| 适用范围 | 全校或某个年级 | 每个班级拥有独立计划 |
| 典型场景 | 月考、期中、期末、模拟考 | 每周测验、晚自习测验 |
| 冲突处理 | 作为正式考试优先显示 | 自动模式下按策略避让大型考试 |
| PDF | 当前大型考试安排 | 按周、按班级生成，可多班合并 |

第一次使用建议先阅读[创建一场大型考试](/features/08-create-major-exam)和[创建一场周测](/features/09-create-weekly-test)。

## V2.8.0 重点功能

### 考试记录管理

- **考试列表**：可按状态、年级/班级、来源、时间范围和创建人筛选，支持关键词搜索与分页；
- **考试详情**：生命周期时间线、累计暂停时长和完整操作记录；
- **生命周期操作**：发布、开考、暂停、继续、延长、结束、归档、反归档与复制；
- **状态展示**：草稿、待开始、进行中、已结束、历史归档；「待开始 / 进行中」按时间窗自动推导。

详见[大型考试模块](/features/03-major-module#考试记录管理-v2-8-0-新增)。

### 诊断日志与错误上报

- 系统设置新增**诊断日志**面板：配置错误发生时保留前后日志、日志保留天数（1–30 天）；
- 日志默认只留在这台设备上，需要时管理员手动上传给作者端；
- 已打开遥测时，影响稳定性的错误（接口 5xx、数据库读写失败、页面渲染异常、分包加载失败）会静默上报，内容经过脱敏。

### 界面重组

- 系统设置拆分为**左侧分组导航 + 分组视图**，新增「诊断日志」与「学校信息」独立面板；
- 管理后台改为左侧边栏，页面级控件集中到顶部上下文栏；
- 运行总览重做呈现：核心状态卡片、运行健康区和待办入口。

### 大屏体验

- 大屏无操作 1 分钟后给出「建议全屏」提示条，不再强行自动进入全屏；
- 考试结束后 15 分钟内提供退出全屏入口与操作指引浮层。

### 继续保留的能力

- 统一班级批量选择器，支持搜索、按年级全选和全选当前筛选结果；
- 一次为多个班级创建独立周测计划，周测 JSON 可批量导入同年级多个班级；
- 多班级周测可合并生成 PDF，每班仍独立分页；
- 年级与班级支持编号区间创建、筛选和批量删除；
- 设备支持多班级筛选和批量解除绑定；
- 支持一班一账号批量创建班级管理员；
- 支持邮箱验证码登录、分级密码重置和超级管理员恢复密钥。

## 推荐的日常工作流

1. 超级管理员维护学校结构、角色和系统设置。
2. 年级管理员发布本年级大型考试，并为各班创建班级管理员。
3. 班级管理员维护自己班级的周测。
4. 每台教室设备在首页选择并绑定实际班级。
5. 发布安排后从运行总览和一台测试设备完成验证。
6. 需要纸质通知时，从预览入口下载 A4 PDF。

::: tip 自动保存
后台编辑会自动同步到数据库。看到“已保存”或同步成功状态后再关闭页面。离线编辑会先进入本地待同步队列，正式发布前仍应在恢复网络后确认云端保存成功。
:::
