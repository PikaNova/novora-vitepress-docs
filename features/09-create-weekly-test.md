# 创建一场周测

周测需要先创建班级计划，再在计划中添加周期周测项。下面以“高一 1 班每周三数学周测”为例。

## 创建前准备

- 已创建目标年级和班级；
- 当前账号拥有周测创建、编辑权限；
- 已设置正确的学期开始日期；
- 已决定统一周表还是 A/B 周；
- 已确认大型考试冲突时的处理规则。

## 第一步：进入周测计划

1. 登录管理后台。
2. 点击顶部 **周测计划**。
3. 选择目标年级，例如“高一”。
4. 选择目标班级，例如“1班”。

如果班级还没有计划，页面会显示空状态并提供新建入口。

## 第二步：新建班级计划

1. 点击 **+ 新建**。
2. 使用班级选择器勾选“高一 1 班”。
3. 计划名称填写：

```text
高一1班日常周测
```

4. 设置生效开始日期，例如学期第一周周一。
5. 选择长期有效，或填写结束日期。
6. 重复周期选择每周。
7. 周次模式选择统一周表；需要单双周时选择 A/B 周。
8. 按学校规则选择是否自动排除法定节假日。
9. 保存计划。

一次勾选多个班级时，每个班级会创建一份独立计划。保存后先检查实际创建数量。

## 第三步：添加数学周测

1. 确认当前计划已选中并启用。
2. 点击 **+ 添加周测**。
3. 名称填写 `数学周测`。
4. 星期选择 `星期三`。
5. 开始时间填写 `19:00`。
6. 结束时间填写 `20:00`。
7. 地点或备注可填写 `本班教室`。
8. 保持“启用此周测”勾选。
9. 点击 **确认并保存**。

如果计划采用 A/B 周，还需要选择：

- A/B 周都进行；
- 仅 A 周；
- 仅 B 周。

结束时间落在第二天时勾选“跨日结束”。普通晚自习周测不要误选。

## 第四步：检查日历

在未来周测日历中逐周查看：

- 周三是否出现数学周测；
- A/B 周标记是否符合预期；
- 日期是否落在计划生效期；
- 法定节假日是否正确暂停；
- 时间和备注是否正确；
- 是否因大型考试被暂停。

日历没有实例时，检查计划是否停用、是否尚未生效、周测项是否停用，以及当前预览周次。

## 第五步：设置冲突策略

在自动运行模式下，根据学校规则配置：

| 暂停范围 | 行为 |
| --- | --- |
| 时间重叠 | 只暂停与大型考试实际重叠的周测 |
| 当天 | 大型考试当天不生成周测 |
| 整个考期 | 从第一科开始到最后一科结束期间暂停周测 |

冲突发生后，可点击日历中的实例选择取消本次、临时调课或本周仍然进行。

## 第六步：单次临时调课

1. 在日历中点击目标周测。
2. 选择临时调整。
3. 设置新日期、开始时间和结束时间。
4. 确认保存。

这只改变本次实例，不会改变以后每周三的周期规则。需要恢复时进入例外日期管理撤销记录。

## 第七步：预览和下载 PDF

1. 点击批量预览或 PDF 入口。
2. 勾选需要导出的一个或多个班级。
3. 点击预览。
4. 逐班、逐周检查内容。
5. 下载 PDF。

一个 PDF 可以包含多个班级，每个班级独立分页，每周一张 A4 页面。

## 批量应用到其他班级

已有标准计划时：

1. 点击 **批量应用** 或“同步至同年级其他班级”；
2. 选择源计划；
3. 设置应用后的计划标题；
4. 使用搜索或按年级全选选择目标班级；
5. 核对班级数量；
6. 执行应用。

每个目标班级得到独立副本，以后修改其中一个班级不会影响其他班级。

## 使用 JSON 导入

简单周测项示例：

```json
{
  "items": [
    {
      "name": "数学周测",
      "weekday": 3,
      "startTime": "19:00",
      "endTime": "20:00",
      "weekType": "all",
      "enabled": true
    }
  ]
}
```

旧版 `items` 数据会覆盖当前周测列表；新版完整计划备份会创建独立计划并保留 A/B 周、例外和节假日设置。V2.5.4 可选择同年级多个班级作为导入目标。
