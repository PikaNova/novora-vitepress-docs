# 管理设备与绑定

教室大屏要能显示本班考试，前提是这台设备在云端有正确的班级绑定。本篇讲怎么绑定、怎么批量清理、怎么远程查看临时考试。

## 一台设备是怎么被识别的

Novora 会为每个浏览器看板生成一个**实例 ID**。ClassIsland 插件有自己独立的实例和密钥；插件配对成功后，后台会把关联的网页看板和插件**合并显示为同一台设备**。

排查时永远要看实例 ID，不要只看设备名称——同班两台设备的名字可能完全一样。

## 绑定一台新设备

1. 在教室设备上打开 Novora 正式地址；
2. 在首页点击「选择年级与班级」；
3. 选择这台设备实际所属的年级和班级；
4. 进入考试大屏，确认显示的考试范围与本班一致；
5. 回到后台「设备管理」，确认这台设备出现在列表里，状态为在线。

::: tip 一台设备只绑定一个班级
绑定关系保存在云端。清除浏览器缓存会丢失本机选择，需要重新选一次；但不会影响后台的记录。
:::

## 设备管理里能看到什么

| 信息 | 用途 |
| --- | --- |
| 在线 / 离线 | 判断设备当前是否可达 |
| 最近心跳时间 | 判断设备是不是刚刚断线 |
| 实例 ID | 区分同班同名设备 |
| 绑定年级与班级 | 确认显示范围 |
| 当前是否正在考试 | 考试期间快速巡检 |
| 当前考试与科目 | 核对大屏显示是否正确 |
| Novora 看板与插件关联状态 | 确认插件是否已配对 |
| 本地临时考试状态 | 查看该设备的课堂随测 |

## 筛选与批量解除绑定

设备多起来之后，逐个操作不现实。批量流程：

1. 用关键词或班级筛选缩小范围；
2. 需要时同时选择多个班级；
3. 使用「选择当前筛选结果」；
4. **核对已选设备数量**；
5. 执行批量解除绑定。

::: warning 先缩小范围再全选
不要在筛选条件不明确时直接全选。解绑会撤销设备访问关系，相关教室需要重新绑定和重新配对。
:::

## 解除绑定会发生什么

- 网页看板失去云端班级绑定，需要回首页重新选择；
- 关联的 ClassIsland 凭据被撤销，需要重新配对；
- 原始客户端密钥不会被接口再次返回。

删除或解绑不是「隐藏记录」，而是撤销访问关系。

## 设备实际开机却显示离线

按顺序排查：

1. 在那台设备上打开首页，确认页面能加载；
2. 访问 `/api/time`，确认返回 JSON；
3. 确认设备绑定没有被清除；
4. 检查浏览器是否休眠、被系统冻结，或教室电脑关机了；
5. 回到后台等待下一次刷新。

超过 90 秒没有心跳的设备不再显示为「正在考试」，这是正常的，避免离线设备长期占着状态。

## 远程查看和管理临时考试

教师在课堂上用「快速开始考试」创建的临时考试，属于那台设备本地。设备管理里可以看到并远程管理：

1. 确认目标实例 ID 和班级正确；
2. 确认是否允许临时考试覆盖当前正式安排；
3. 确认起止时间符合课堂计划；
4. 操作后确认目标设备已经收到同步。

临时考试适合课堂随测，**不应**代替全校正式大型考试。

## 换教室怎么办

1. 后台「设备管理」解除旧绑定；
2. 在教室设备上回首页，选择新的年级和班级；
3. 如果这台设备装了 ClassIsland 插件，重新走一次配对；
4. 回到设备管理确认绑定已更新；
5. 在大屏上确认显示范围正确。

## 推荐做的一件小事

部署时给每台设备贴个物理标记，写上实例 ID 后四位。排查时不用来回确认哪台是哪台，尤其是同年级多台设备的情况。
