# V2.8.0 新功能速览

Novora V2.8.0 把系统从「能发布考试的大屏工具」升级为「基础考试管理系统」：考试有了独立记录、
生命周期和操作历史，系统有了诊断日志与错误上报，管理后台与系统设置的界面也重新组织。

本页是索引页，每一项都链到详细章节。第一次升级到这个版本的管理员，建议先读完本页。

::: tip 升级影响
旧客户端的读取契约不变。教室大屏、ClassIsland 插件和已有考试数据不需要做额外操作，直接升级即可。

需要留意的是**操作方式的变化**：新建考试保存后即为「已发布」，到点由系统自动开考，
不再有人工「开考」按钮；提前收场改为「申请停止」，由系统判定后结束，异常时有「强制结束」兜底。
:::

## 一、考试记录与系统驱动生命周期

每场考试都有独立记录，带状态、时间线和操作历史，不再只是「一份可以发布的时间表」。

- **考试记录列表**：按状态、年级/班级、来源、时间范围、创建人筛选，支持关键词搜索与分页，
  并按账号的数据范围自动过滤（年级管理员只看得到本年级）。
- **考试详情**：生命周期时间线、累计暂停时长、完整操作记录（谁在什么时候做了什么），
  创建人显示姓名而不是账号编号。
- **系统驱动生命周期**：新建即发布 → 到点自动开考 → 提交停止申请后由系统判定结束；
  暂停、继续、延长仍由管理员操作，暂停时长不计入实际用时。
- **复制考试先落草稿**：复制不会产生重复记录，复制结果进入草稿，改完再发布。
- **状态自动推导**：草稿 / 待开始 / 进行中 / 停止中 / 已结束 / 历史归档，
  其中「待开始 / 进行中 / 停止中」按时间窗、实际开考时间与暂停时长算出来，不需要人工维护。

详细说明：[大型考试 · 考试记录管理](/features/03-major-module)、[考试记录管理预览](/effect/12-exam-records)。

## 二、学校考试公告与发布前检查

学校可以自己向教室大屏下发考试公告，和作者端的软件公告互不影响。

- **投放范围**：全校 / 指定年级 / 指定班级。
- **级别**：普通（大屏上可关闭）或紧急（置顶且不可关闭，盖过作者端软件公告）。
- **大屏排版**：标准卡片（适合通知与长内容）、大字海报（适合一句话紧急通知）、
  公告栏（浅色纸张风，适合长文），正文支持 Markdown 与图片。
- **有效期**：30 分钟 / 2 小时 / 当天 / 不过期，发出后教室大屏 1 分钟内更新。
- **公告记录**：可查看生效中 / 已过期 / 已撤回的历史，需要时随时撤回。
- **发布前检查**：保存或发布前提示科目时间是否完整、目标范围内有多少台设备在线，
  只提示不阻断，用来提前发现「时间没填全」「教室设备没上线」。

详细说明：[大型考试 · 考试公告下发](/features/03-major-module)、[考试大屏 · 学校公告窗口](/effect/02-screen)。

## 三、诊断日志与错误上报

- **诊断日志分组**：可设置错误发生前后保留的日志时间范围、日志保留天数（1–30 天，超期自动清除），
  以及由管理员手动上传日志包。
- **默认不外发**：日志只留在当前设备上，只有管理员主动点击上传才会发送给作者端。
- **静默错误上报**：打开遥测后，影响稳定性的错误（接口 5xx、数据库读写失败、页面渲染异常、
  分包加载失败等）会静默上报；权限不足、登录过期、密码错误等正常业务提示不会被当作系统错误。
- **脱敏与降级**：上报内容不包含考试正文、管理员密码、恢复密钥和登录会话；作者端不可用时自动跳过。

详细说明：[其他功能 · 系统设置](/features/10-other-features)。

## 四、界面重组

- **系统设置**改为左侧分组导航 + 分组视图，桌面端不再显示冗余分组胶囊，
  新增「诊断日志」与「学校信息」两个独立分组。
- **管理后台**导航改为左侧边栏，页面级筛选与操作按钮集中到顶部上下文栏，
  页面滚动时导航保持贴边，不再被内容顶开。
- **运行总览**重做呈现：核心状态卡片、运行健康区和常用待办入口，
  设备心跳、考试排期、数据同步三个维度分别判断健康状态。
- **审计日志全部显示中文**：动作名称为中文，原始机器码只作为悬停提示保留，方便排查。

详细说明：[功能总览](/features/01-feature-overview)、[运行总览](/features/02-overview-module)、
[用户与权限](/features/07-users-module)。

## 五、大屏与设备

- **建议全屏提示条**：大屏无操作 1 分钟后给出提示条，点击才进入全屏，不再强行自动进入。
- **结束退出入口**：考试结束后 15 分钟内提供退出全屏入口和操作指引浮层，方便监考老师离场操作。
- **设备命令回执**：设备命令的领取、确认、失败与回执状态会持久保存，管理端可以查看执行情况。
- **设备状态按优先级展示**：考试详情里的设备列表按「显示异常 → 在线 → 离线」排序，
  同一组内按最近在线时间倒序，设备很多时优先看到的仍是需要处理的教室。
- **统一日期时间选择器**：手机端与桌面端使用同一套选择方式。

详细说明：[考试大屏预览](/effect/02-screen)、[提醒设置](/features/15-notifications)、
[管理设备与绑定](/features/12-manage-devices)。

| 补充项 | 变化 |
| --- | --- |
