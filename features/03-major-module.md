# 模块二：大型考试

大型考试用于管理有明确日期、起止时间和科目安排的正式考试，例如月考、期中考试、期末考试和模拟考试。

## 数据结构

一场大型考试包含：

```text
大型考试
├─ 名称，例如“高三一模”
├─ 适用范围，例如“高三”或“全校”
└─ 多个分考试
   ├─ 语文：具体开始与结束时间
   ├─ 数学：具体开始与结束时间
   └─ 英语：具体开始与结束时间
```

先创建大型考试容器，再逐科添加分考试。只有创建了启用的分考试，大屏才有可执行的具体安排。

## 考试切换和年级范围

后台按当前年级显示适用考试。切换年级后，会自动选择该年级对应的考试；全校考试会出现在所有年级绑定设备上。

大屏不使用管理员后台当前选中的年级，而是根据设备实际绑定班级自动匹配。因此在后台切换年级不会改变其他教室设备的班级绑定。

## 可以执行的操作

- 新建、切换、设置和删除大型考试；
- 设置全校或指定年级范围；
- 添加、编辑、启用、停用和删除分考试；
- 调整分考试顺序；
- 导入或导出大型考试 JSON；
- 网页预览并导出 A4 PDF；
- 查看考试状态和科目数量；
- 删除后立即撤销。

## 时间校验

保存分考试时系统会检查：

- 科目名称不能为空；
- 开始和结束时间不能为空；
- 结束时间必须晚于开始时间；
- 与其他启用科目重叠时要求再次确认；
- 超过 6 小时的考试要求确认是跨天或特殊安排。

如果只是暂时不想显示某科，可停用该科，不必立即删除。

## 范围优先级

同一时间存在不同范围的正式考试时，调度优先使用更具体的范围：

```text
班级范围 > 年级范围 > 全校范围
```

V2.5.4 当前新建大型考试界面主要提供全校或年级范围。已有兼容数据仍按调度规则处理。

## 发布前检查

- 考试名称与通知一致；
- 适用年级正确；
- 日期、时区和上下下午正确；
- 每科结束时间晚于开始时间；
- 不需要显示的草稿科目已停用；
- PDF 顺序正确；
- 一台目标班级设备显示正确。

完整步骤见[创建一场大型考试](/features/08-create-major-exam)。
