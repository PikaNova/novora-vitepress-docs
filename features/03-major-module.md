# 模块二：大型考试

大型考试用于管理有明确日期、起止时间和科目安排的正式考试，例如月考、期中考试、期末考试和模拟考试。

## 数据结构

一场大型考试包含：

```text
大型考试
├─ 名称，例如“高三一模”
├─ 适用范围，例如“高三”或“全校”
└─ 多个分考试
   ├─ 语文：具体开始与结束时间
   ├─ 数学：具体开始与结束时间
   └─ 英语：具体开始与结束时间
```

先创建大型考试容器，再逐科添加分考试。只有创建了启用的分考试，大屏才有可执行的具体安排。

## 考试切换和年级范围

后台按当前年级显示适用考试。切换年级后，会自动选择该年级对应的考试；全校考试会出现在所有年级绑定设备上。

大屏不使用管理员后台当前选中的年级，而是根据设备实际绑定班级自动匹配。因此在后台切换年级不会改变其他教室设备的班级绑定。

## 可以执行的操作

- 新建、切换、设置和删除大型考试；
- 设置全校或指定年级范围；
- 添加、编辑、启用、停用和删除分考试；
- 调整分考试顺序；
- 导入或导出大型考试 JSON；
- 网页预览并导出 A4 PDF；
- 查看考试状态和科目数量；
- 删除后立即撤销；
- 使用批量预设快速创建分考试：科目多选、时间选择器、自定义科目名与全校共享预设；
- 大型考试冲突会给出醒目提醒，新建弹窗支持更大尺寸与立即开始。

## 时间校验

保存分考试时系统会检查：

- 科目名称不能为空；
- 开始和结束时间不能为空；
- 结束时间必须晚于开始时间；
- 与其他启用科目重叠时要求再次确认；
- 超过 6 小时的考试要求确认是跨天或特殊安排。

如果只是暂时不想显示某科，可停用该科，不必立即删除。

## 范围优先级

同一时间存在不同范围的正式考试时，调度优先使用更具体的范围：

```text
班级范围 > 年级范围 > 全校范围
```

新建大型考试界面主要提供全校或年级范围。已有兼容数据仍按调度规则处理。

## 考试记录管理（V2.8.0 新增）

V2.8.0 把「能发布考试」升级为「能管理考试」：每场考试都有独立记录，带状态、时间线和操作历史。

![考试记录列表](/pictures/exam-records-list.png)

### 考试列表

进入「大型考试」后，列表支持按以下条件筛选：

| 筛选项 | 说明 |
| --- | --- |
| 状态 | 草稿 / 待开始 / 进行中 / 已结束 / 历史归档 |
| 年级、班级 | 按适用范围过滤 |
| 来源 | 正式排考或快速发布 |
| 时间范围 | 按考试日期过滤 |
| 创建人 | 按操作账号过滤 |
| 关键词 | 搜索考试名称或编号 |

列表分页显示，并会自动按账号的数据范围过滤——年级管理员只能看到本年级的记录。归档后的考试默认不出现在列表里。

### 考试详情

点开一场考试可以看到：

- **生命周期时间线**：什么时候发布、开考、暂停、结束、归档；
- **累计暂停时长**：暂停时间不计入实际用时；
- **操作记录**：谁在什么时间做了什么操作，包含原始状态和目标状态。

### 生命周期操作

| 操作 | 说明 |
| --- | --- |
| 发布 | 草稿转为已发布，之后可以开考 |
| 开考 | 记录实际开始时间 |
| 暂停 | 记录暂停时刻 |
| 继续 | 结算本轮暂停时长 |
| 延长 | 顺延结束时间（需提供幂等键，防止重复提交） |
| 结束 | 记录实际结束时间 |
| 归档 | 从默认列表隐藏，保留历史 |
| 反归档 | 从归档状态恢复 |
| 复制 | 复制一场考试用于下次使用（需提供幂等键） |

合法状态转换才允许执行，非法的跳转会返回冲突提示。所有转换都会写入审计日志。

### 状态是怎么算出来的

持久保存的状态只有四个：`草稿 → 已发布 → 已结束 → 已归档`。「待开始 / 进行中」是按考试时间窗和暂停时长推导出来的展示状态，不单独存库，因此不会出现状态和时间对不上的情况。

## 发布前检查

- 考试名称与通知一致；
- 适用年级正确；
- 日期、时区和上下下午正确；
- 每科结束时间晚于开始时间；
- 不需要显示的草稿科目已停用；
- PDF 顺序正确；
- 一台目标班级设备显示正确。

完整步骤见[创建一场大型考试](/features/08-create-major-exam)。
