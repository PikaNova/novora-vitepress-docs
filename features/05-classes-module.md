# 模块四：年级与班级

年级与班级是所有考试范围、周测计划、设备绑定和用户权限的基础。初始化时会创建第一版学校结构，之后在本模块维护。

## 能做什么

- 新建、重命名和删除年级；
- 在年级下新建、重命名和删除班级；
- 按任意编号区间批量创建班级；
- 使用关键词筛选班级；
- 全选当前筛选结果并批量删除；
- 查看每个年级和班级的基本数量。

## 批量创建班级

选择目标年级后，可以输入编号起点和终点。例如从 1 到 12，可一次创建：

```text
1班、2班、3班……12班
```

V2.5.4 支持任意编号区间，不要求从 1 开始。创建前检查现有班级，避免得到重复或不符合校内命名习惯的记录。

## 批量删除

1. 输入关键词或选择年级进行筛选；
2. 检查结果范围；
3. 使用“全选筛选结果”；
4. 再次核对已选数量；
5. 执行批量删除。

删除班级会同步清理相关周测计划、班级绑定和旧考试范围。此操作影响较大，执行前应备份并避开正在考试时段。

## 权限规则

- 超级管理员可以创建和删除年级、管理全校班级；
- 年级管理员只能管理授权年级中的班级；
- 年级管理员不能创建或删除年级；
- 班级管理员和只读用户通常只读取授权结构。

服务端会校验范围，不能通过修改页面参数管理未授权年级。

## 修改结构后的检查

- 周测计划仍指向正确班级；
- 教室设备没有显示“未识别班级”或被撤销；
- 管理员账号的数据范围仍符合职责；
- 大型考试适用年级没有失效；
- 首页可以重新选择正确班级。

::: warning 不要用删除代替改名
只是名称调整时应使用重命名。删除后新建会产生新的内部 ID，原设备、计划和权限不会自动当作同一班级恢复。
:::
