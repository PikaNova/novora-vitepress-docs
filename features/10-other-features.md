# 其他功能

除六个后台模块外，Novora 还提供教室大屏、快速考试、PDF、公告文档、PWA、JSON 导入、ClassIsland 和更新维护功能。

## 快速开始考试

考试大屏支持在当前设备创建本地临时考试。V2.5.4 使用三步向导：

### 1. 选择科目

从常用科目按钮选择，或输入其他科目名称。

### 2. 设置时间

选择：

- 立即开始；
- 延迟若干分钟开始；
- 指定日期时间开始；
- 常用考试时长或自定义时长。

### 3. 确认选项

检查科目、开始时间、结束时间和冲突提示，并决定临时考试是否覆盖正式安排。

临时考试只属于当前设备，适合课堂测验，不应代替全校正式大型考试。手机使用全屏向导和固定底部操作区，桌面使用紧凑弹窗。

## 13 套考试大屏设计

大屏提供多种亮色、深色、黑板、编辑、紧急和控制台风格设计。可在本地设置或大屏设计切换器中选择。

设计只影响当前设备外观，不改变云端考试时间。正式使用前检查：

- 投影或大屏上的对比度；
- 长科目名称是否完整；
- 倒计时是否清晰；
- 全屏、同步按钮和状态是否重叠；
- 夜间教室是否过亮。

## 班级选择和本地设置

每台设备只绑定一个班级。首页或本地设置中的可搜索班级选择器用于选择年级和班级。

本地设置还可以管理：

- 当前设备班级；
- 大屏设计；
- 标题、正文和时间数字字体；
- 动效和显示偏好；
- 本机相关设置。

清除浏览器站点数据可能移除本机选择，但不会直接删除 Neon 中的学校和考试数据。

## 考试安排预览和 A4 PDF

无需管理员账号，也可以从当前设备进入只读安排预览：

- 按日期查看当前班级安排；
- 下载带学校、班级、实例、导出时间和水印的 PDF；
- 大型考试使用固定 A4 布局；
- 周测每周一张 A4，可多班合并导出；
- 手机和电脑使用同一固定尺寸渲染。

PDF 只用于发布和打印预览，正式调度仍以云端数据和设备绑定为准。

## 公告与使用文档

首页和管理后台可以查看作者端发布的公告与文档。初始化第 5 步会推荐打开 HTTPS 文档，但不再强制弹窗或等待。

初始化后可从以下入口再次查找：

```text
首页 → 系统公告 → 文档
管理后台 → 更多 → 查看公告 → 文档
```

如果浏览器阻止弹出窗口，无需修改浏览器权限；可继续初始化，并稍后从系统公告手动获取链接。

## 提醒管理

管理员可以配置考试各阶段提醒，例如开考前 15 分钟、5 分钟、开考、结束前和结束状态。提醒设置影响大屏提示，应在一台测试设备上完整验证。

## JSON 导入导出与 AI 提示词

大型考试和周测均支持 JSON 导入导出。导入界面可生成严格的识图提示词，把提示词复制到支持图片识别的 AI 软件后，再将纯 JSON 结果粘贴回 Novora 校验。

Novora 本身不会把考试表照片发送给 AI 服务。使用外部 AI 时应遵守学校的数据要求，并人工复核日期、时间和范围。

## ClassIsland 联动

ClassIsland 插件通过 `/api/exams` 与 Novora 配对，获得当前班级有效考试时间线，并可在考前自动打开大屏和发送提醒。

基本流程：

1. 插件填写 Novora 基础网址；
2. 发起一次性配对；
3. 浏览器选择年级和班级；
4. 确认连接；
5. 后台设备管理检查关联状态。

详细步骤见[ClassIsland 插件](/appendix/c-classisland)。

## PWA 和离线缓存

支持的浏览器可以把 Novora 添加到桌面。Service Worker 会缓存应用外壳，短时断网时可保留部分已有只读内容。

离线缓存不是数据库备份。管理操作只有在恢复网络并显示同步成功后，才算真正写入 Neon。

## 系统设置

具有设置权限的管理员可以维护：

- 运行模式和冲突规则；
- 学期起始日期与 A/B 周；
- 节假日和调度设置；
- 版本检查与一键重新部署；
- 遥测同意状态；
- 数据维护和分模块重置。

数据库重置属于高风险操作。执行前必须备份并确认模块范围。

## 更新和重新部署

正式部署必须配置 `VERCEL_DEPLOY_HOOK_URL`。超级管理员可在“版本与更新”检查作者发布的最新版本；更新时必须先在 GitHub 将作者仓库同步到自己的 Fork `main`。随后 Vercel 会自动部署该提交；**一键部署更新**只会触发当前 Fork 的 Deploy Hook 重新构建，不能获取作者仓库的新代码。

V2.5.6 起，该卡片提供可展开的 **查看后续更新完整流程**，直接说明同步 Fork、备份、检查版本、触发部署、验收和回滚。更完整的维护记录要求见[日常维护](/guide/12-maintenance)。

V2.5.5 会在首次初始化后自动生成超级管理员恢复密钥，不再要求 `ADMIN_RECOVERY_KEY` 环境变量。明文只显示一次，必须由部署负责人安全保存。
