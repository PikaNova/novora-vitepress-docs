# 模块三：周测计划

周测计划用于维护按星期长期重复的测验。每个班级拥有独立计划，可以设置生效期、重复周期、A/B 周、节假日和单次例外。

## 计划和周测项

```text
班级周测计划
├─ 计划名称、生效日期、重复规则
├─ 周一 19:00 数学周测
├─ 周三 19:00 英语周测
└─ 周五 18:30 物理周测
```

“计划”控制整体周期；“周测项”控制具体星期、时间和名称。一个班级可以保留多个计划，但应明确当前生效计划。

## 计划设置

- 一个或多个目标班级；
- 计划名称；
- 生效开始和结束日期，或长期有效；
- 每周或每若干周重复；
- 统一周表或 A/B 周；
- 是否自动排除内置法定节假日；
- 启用或停用整个计划。

V2.5.4 新建时可一次选择多个班级，系统会为每个班级创建一份独立计划。后续修改一个班级，不会联动修改其他副本。

## 周测项设置

- 名称；
- 星期一至星期日；
- A/B 周都进行、仅 A 周或仅 B 周；
- 开始时间和结束时间；
- 是否跨日结束；
- 地点或备注；
- 是否启用。

## 批量功能

- 将当前计划批量应用到多个班级；
- 一键同步至同年级其他班级；
- 把 JSON 导入同年级多个班级；
- 搜索班级、按年级全选或全选筛选结果；
- 批量预览多个班级并生成一个 PDF。

批量 PDF 中每个班级独立分页，每周使用一张标准 A4 页面。

## 冲突和例外

自动运行模式下，大型考试可以按策略暂停周测：

- 仅暂停时间重叠的周测；
- 暂停考试当天全部周测；
- 暂停整个考期内的周测。

对某一次周测还可以：

- 取消本次；
- 临时调整日期和时间；
- 冲突时强制本周仍然进行；
- 在例外日期管理中撤销调整。

单次调整不会修改周期规则本身。

## 日历预览

预览按周一至周日逐周切换，并显示：

- 日期和周次；
- A/B 周；
- 正常、暂停或强制执行状态；
- 法定节假日；
- 临时调课结果。

完整步骤见[创建一场周测](/features/09-create-weekly-test)。
