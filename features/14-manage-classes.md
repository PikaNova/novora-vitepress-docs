# 维护年级与班级

年级与班级是所有考试范围、周测计划、设备绑定和用户权限的基础。结构改错一次，后面要收拾很久，所以本篇把"什么时候该改什么"讲清楚。

## 三类改动，风险完全不同

| 改动 | 风险 | 建议 |
| --- | --- | --- |
| 改名称 | 低 | 优先用这个 |
| 新增年级或班级 | 低 | 随时可做 |
| 删除年级或班级 | **高** | 会连带清理周测、绑定和旧范围 |

::: warning 改名和删重建不是一回事
删除后再新建会产生新的内部 ID，原来的设备绑定、周测计划和权限**不会**自动跟随到这个"同名"班级上。只是名称变化时，一定要用重命名。
:::

## 批量创建班级

新生入学或整栋楼扩班时用这个：

1. 进入「年级与班级」；
2. 选择目标年级；
3. 点击批量创建；
4. 输入编号起点和终点，例如 `1` 到 `12`；
5. 确认预览，检查是否与现有班级重复；
6. 执行创建。

支持任意编号区间，不要求从 1 开始。例如从 5 到 9 会创建 5 班到 9 班。

::: tip 创建前先看一眼现有班级
重复创建同名班级不会报错，但会让后续选择器里出现两个"1 班"，很难分辨。
:::

## 批量删除

风险最高的一步，按这个顺序做：

1. **先备份数据库**；
2. 输入关键词或选择年级筛选；
3. 检查筛选结果范围；
4. 使用「全选筛选结果」；
5. **再次核对已选数量**；
6. 避开正在考试或即将考试的时段；
7. 执行批量删除。

删除班级会同步清理：

- 该班的周测计划；
- 设备的班级绑定；
- 旧考试的适用范围。

## 常见的四种结构变动

### 分班

把一个班的同学分到两个新班：

1. 新建两个班级；
2. 把原班的周测用「批量应用」复制到两个新班；
3. 逐台设备重新绑定到实际的班级；
4. 为两个新班创建班级管理员；
5. 确认无误后再删除原班。

**先建新、迁移、验证，最后删旧**，顺序不要颠倒。

### 合班

两个班合成一个：

1. 保留其中一个班级作为合并后的班级，改名到正确的名称；
2. 把另一个班的周测复制或合并到保留的班级；
3. 把设备重新绑定到保留的班级；
4. 删除不再使用的那个班级；
5. 停用或改派原班级管理员的权限。

### 年级升级

学年结束时高一的班级变成高二：

1. 如果只是年级归属变化，优先**重命名年级**，不要删重建；
2. 检查各年级管理员的授权范围是否需要跟着调整；
3. 检查新学期周测计划的生效日期；
4. 检查设备的绑定是否仍然正确。

### 班级改名

例如"1班"改成"高一（1）班"：

直接用重命名。设备绑定、周测计划、权限和历史考试都不会受影响。

## 改完之后要检查什么

- [ ] 周测计划仍指向正确班级；
- [ ] 教室设备没有变成"未识别班级"或被撤销绑定；
- [ ] 管理员账号的数据范围仍符合职责；
- [ ] 大型考试的适用年级没有失效；
- [ ] 首页能重新选择到正确的班级；
- [ ] 运行总览没有出现新的冲突提醒。

## 多班统一维护的技巧

如果多个班级应该有一模一样的周测：

1. 先把一个班配成标准；
2. 用「批量应用」或「同步至同年级其他班级」下发；
3. 注意每个目标班得到的是**独立副本**，以后改其中一个不会影响其他；
4. 需要再次统一时，重新下发一次即可。
