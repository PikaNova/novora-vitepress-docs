# 模块五：设备管理

设备管理用于查看教室 Novora 看板和 ClassIsland 插件的在线状态、班级绑定与当前考试，并执行解除绑定或临时考试管理。

## 什么是一台设备

Novora 会为浏览器看板生成实例 ID。ClassIsland 插件也有独立实例和密钥。完成插件配对后，后台会把关联的网页看板和插件合并展示为同一台教室设备。

## 可查看的信息

- 在线或离线状态；
- 最近心跳时间；
- 设备实例 ID；
- 绑定年级和班级；
- 当前是否正在考试；
- 当前考试和科目；
- Novora 看板与 ClassIsland 的关联状态；
- 本地临时考试状态。

## 筛选和批量操作

V2.5.4 支持：

- 按关键词和班级筛选；
- 同时选择多个班级；
- 选择当前筛选结果；
- 批量解除 Novora 看板与 ClassIsland 绑定。

批量操作前先缩小筛选范围，并核对已选设备数量。不要在不清楚筛选条件时全选。

## 解除绑定会发生什么

- 当前网页看板失去云端班级绑定；
- 关联 ClassIsland 凭据被撤销；
- 设备需要回到首页重新选择班级；
- ClassIsland 插件需要重新发起浏览器配对；
- 原始客户端密钥不会被接口再次返回。

删除或解绑不是简单“隐藏记录”，而是撤销设备访问关系。

## 临时考试管理

设备管理可以查看或远程管理设备上的临时考试。临时考试主要用于单个教室临时测验，不会替代全校正式大型考试数据。

使用前确认：

- 目标实例 ID 和班级正确；
- 临时考试是否允许覆盖当前正式安排；
- 开始和结束时间符合课堂计划；
- 操作后目标设备已经收到同步。

教师也可以直接在考试大屏使用[快速开始考试](/features/10-other-features#快速开始考试)。

## 在线判断

设备状态会定期刷新。超过 90 秒没有心跳的设备不再显示为“正在考试”。如果设备实际开机却离线：

1. 在该设备打开首页；
2. 检查自定义域名和 `/api/time`；
3. 检查设备绑定；
4. 检查浏览器是否休眠或被系统冻结；
5. 返回后台等待下一次刷新。
