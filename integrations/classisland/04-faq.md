# 4. 插件常见问题

## 无法打开配对页

先在同一台设备的浏览器里手动打开两个地址：

```text
https://exam.example.com
https://exam.example.com/api/time
```

第一个应显示 Novora 首页，第二个应返回 JSON。都正常再回到插件重新发起配对。

仍然打不开时，依次检查：浏览器是否被安全策略限制、系统默认浏览器是否设置、教室网络能否访问该地址。

## 提示配对令牌过期

令牌有效期 5 分钟。回到插件重新点击「开始配对」，不要刷新或复用旧的 token 页面。

## 同步不到考试

按顺序检查：

1. 插件里显示的基础网址是否正确（不要带 `/login` 或 `/exam`）；
2. 配对时选择的班级是否就是这台设备实际所属的班级；
3. 该班级是否确实有适用的考试（大型考试按年级范围匹配，周测按班级匹配）；
4. 考试的分科目是否处于启用状态；
5. 在 Novora 后台「设备管理」确认这台设备在线。

## 提醒时间不准

插件使用服务端时间校正调度。如果提醒整体偏移，先检查教室电脑的时区设置是否正确（应为中国标准时间），再检查系统时间是否偏差过大。

## 自动打开大屏没生效

自动打开需要在教室设备上有可用的默认浏览器。Linux 环境如果缺少默认浏览器，或 `xdg-open` / `gio open` 不可用，自动打开会失败，但提醒本身仍然可用。

## 删除设备后就不同步了

这是预期行为。删除设备会撤销插件凭据，需要重新配对。批量解除绑定前请确认筛选范围，避免误伤正常教室。

## 换教室后要做什么

1. 后台「设备管理」解除旧绑定；
2. 教室设备首页重新选择新的年级和班级；
3. 插件重新配对；
4. 后台确认绑定已更新。

## 升级 Novora 后插件要升级吗

不需要。插件接口在 v2.7 / v2.8 保持兼容，升级主程序后已完成的配对继续有效。

## 想自己做一个类似的接入

参考[考试数据接口](/integrations/02-api)。核心是按班级读取有效考试时间线，并在本地做时间校正和提醒去重。
