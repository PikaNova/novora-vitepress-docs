# 2. 配对与设备绑定

配对只需要做一次，之后插件会长期同步。整个过程不需要在插件里输入管理员密码。

## 第一步：填写 Novora 地址

在插件设置中只填写**基础网址**：

```text
https://exam.example.com
```

不要填写下面这些：

```text
https://exam.example.com/login
https://exam.example.com/api/exams
https://exam.example.com/exam
```

插件会自动生成接口、配对页和考试大屏的路径。内网部署时填 `http://192.168.1.10:3000` 这样的地址也可以。

## 第二步：发起配对

1. 在插件中点击「开始配对」；
2. 插件向 Novora 请求一次性配对令牌；
3. 系统浏览器自动打开 `/plugin/connect?token=...`；
4. 在网页中选择正确的**年级和班级**；
5. 点击确认连接；
6. 返回 ClassIsland 查看同步状态。

配对令牌有效期为 **5 分钟**。超时后不要重复刷新旧页面，回到插件重新发起配对。

## 第三步：确认配对结果

配对完成后在两个地方确认：

**插件侧**：显示已连接，并能看到当前班级的考试时间线。

**Novora 后台**：打开「设备管理」，该插件会与对应的网页看板合并显示为同一台设备，可以看到绑定班级和在线状态。

## 客户端密钥是怎么保存的

配对成功后，插件会获得一个客户端密钥。Novora 只保存它的 **SHA-256 摘要**，接口不会再次返回原始密钥。因此密钥遗失只能重新配对，不能找回。

## 更换教室或班级

设备搬到别的教室时：

1. 在 Novora 后台「设备管理」解除该设备的绑定；
2. 在教室设备上打开首页，重新选择新的年级和班级；
3. 在插件中重新发起配对；
4. 回到设备管理确认绑定已更新。

不要只是在插件里改地址了事——绑定关系在服务端，必须重新走一次配对。

## 解除绑定会发生什么

- 网页看板失去云端班级绑定，需要回到首页重新选择；
- 插件凭据被撤销，需要重新配对；
- 原始客户端密钥不会被接口再次返回。

删除设备或批量解除绑定属于撤销访问关系，不是「隐藏记录」。批量操作前先缩小筛选范围并核对已选设备数量。

## Linux 教室设备

插件打开浏览器时先使用系统默认方式，失败后会尝试 `xdg-open` 和 `gio open`。如果配对页打不开，先在同一台设备的浏览器里手动访问 Novora 基础网址确认网络，再检查桌面环境是否有默认浏览器。
