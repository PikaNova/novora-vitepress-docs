# 场景演练

清单告诉你"要做什么"，演练告诉你"按什么顺序做、做到什么程度算完成、出问题往哪走"。这一栏按真实场景组织。

| 场景 | 什么时候用 |
| --- | --- |
| [第一次全校上线](/playbooks/01-go-live) | 系统刚部署完，准备正式给全校用 |
| [考试当天](/playbooks/02-exam-day) | 大型考试当天，从考前到晚自习的完整安排 |
| [假期与开学](/playbooks/03-holiday) | 长假前后，设备收存、恢复和开学准备 |

每个演练都包含四部分：**时间线、检查项、应急预案、收尾归档**。

如果你只想要任务清单，看[学期切换清单](/admin/05-semester-checklist)。演练是把清单按时间铺开。
