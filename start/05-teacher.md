# 老师视角：怎么看考试安排

这一页写给不用管理后台的老师。整个流程不需要账号，也不会改到任何数据。

## 我要做的只有两件事

1. 打开查询地址；
2. 选择自己的年级和班级。

看到的就是本班的考试安排。

## 怎么查到本班考试

### 方式一：教室大屏（最常用）

教室电脑上通常已经打开大屏。屏幕上会显示：

- 当前或下一场考试的名称和科目；
- 倒计时；
- 开考前提醒。

设备已经绑定好本班，老师不需要操作。

### 方式二：网页安排预览（不用登录）

1. 打开学校给的 Novora 网址；
2. 进入「安排预览」；
3. 选择要查看的年级和班级；
4. 按日期查看当天和之后的安排。

这个入口**只读**，看不到管理功能，也改不了任何东西。

### 方式三：下载 PDF 打印

在安排预览页面可以直接下载 A4 PDF：

- 大型考试导出当前考试安排；
- 周测按周导出，可一次选多个班级合并成一份，每个班独立分页；
- 可以导出未来 1–3 周的范围。

需要张贴或发给家长时用这个。

## 想查别的班可以吗

可以。预览入口允许切换年级和班级，因为是只读的。这也是巡考人员常用的方式。

## 我能不能改点什么

预览入口不能修改。需要调整时找对应的人：

| 想改什么 | 找谁 |
| --- | --- |
| 本班周测时间、临时调课 | 班级管理员 |
| 本年级大型考试 | 年级管理员 |
| 学校结构、账号权限 | 超级管理员 |
| 大屏本身显示不出来 | 电教老师或设备负责人 |

## 大屏上没显示我班的考试

先确认三件事：

1. 这台大屏绑定的是不是本班（屏幕上会显示班级）；
2. 这场考试是不是适用本班（年级考试适用整个年级）；
3. 是不是刚改过还没同步——等一分钟再看。

仍然不对就告诉班级管理员，说明**哪场考试、哪个班、现在屏幕上显示什么**，比"大屏坏了"有用得多。

## 常见疑问

**手机能看吗？**
能。用手机浏览器打开同样的地址和预览入口即可。

**需要装软件吗？**
不需要。用浏览器打开地址就行。想在手机桌面上留个图标，可以用浏览器的"添加到主屏幕"。

**打印出来会和屏幕不一样吗？**
不会。PDF 和屏幕读的是同一份数据，只是排版按 A4 固定尺寸生成。

**看不到下周的安排？**
周测预览默认从当前周开始，可以往后翻。如果下周确实没有安排，可能是计划到期或那周被大型考试暂停了。

**为什么考试开始时会有弹窗？**
那是提醒设置，属于正常行为，用于提示学生准备。
