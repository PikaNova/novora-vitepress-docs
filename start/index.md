## 一句话选部署方式

- 没有可长期开机的服务器，希望老师和学生在家也能访问 → **Vercel 云端**
- 要求数据不出校园网，或教室网络访问境外服务不稳定 → **本地 / 内网**

完整对比见[选择部署方式](/guide/00-deploy-paths)。
