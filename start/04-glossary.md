# 术语表

读文档时遇到不认识的词，回到这一页查。按主题分组，每组按常用程度排序。

## 考试与调度

| 术语 | 含义 |
| --- | --- |
| **大型考试** | 有明确日期和起止时间的正式考试，例如月考、期中、期末。一场大型考试由多个分科目组成。 |
| **分考试** | 大型考试下的单个科目，例如「语文 08:30–10:30」。只有启用的分科目才会在大屏显示。 |
| **周测计划** | 按星期长期重复的测验安排。每个班级有独立计划，可设生效期、重复周期和例外。 |
| **周测项** | 周测计划下的单条安排，例如「周三 19:00 数学」。 |
| **快速考试 / 临时考试** | 在某台设备上临时创建的考试，只在该设备显示，适合课堂随测。 |
| **A/B 周** | 单双周交替的周期。由「学期开始日期」和「周次模式」共同决定，可让某项周测只在 A 周或 B 周进行。 |
| **统一周表** | 每周安排相同的模式，不使用 A/B 周交替。 |
| **冲突策略** | 自动运行模式下，大型考试与周测时间重叠时的处理方式：仅暂停重叠项、暂停当天全部、或暂停整个考期。 |
| **运行模式** | 大屏显示什么：仅大型考试、仅周测，或自动调度。 |
| **适用范围** | 一场考试对哪些年级或班级生效。同时存在多个范围时，班级 > 年级 > 全校。 |
| **显示状态 / 实际状态** | 显示状态是「草稿 / 待开始 / 进行中 / 已结束 / 已归档」；其中进行中按时间窗自动推导，不单独存库。 |

## 账号与权限

| 术语 | 含义 |
| --- | --- |
| **超级管理员** | 系统负责人。独占角色配置、系统设置、数据维护和版本更新。 |
| **年级管理员** | 管理授权年级内的考试、周测、班级、设备和下级用户。 |
| **班级管理员** | 管理本班周测和设备，查看适用于本班的考试。 |
| **班级访客** | 只读角色（原「巡考员」），用于巡考和教务查看，并可导出 PDF。 |
| **数据范围** | 一个账号能看哪些年级或班级。它和模块权限是两回事，两者都要满足。 |
| **恢复密钥** | 以 `NVR-` 开头的一次性密钥，在初始化最后生成，用于所有超级管理员都忘记密码时应急恢复。数据库只存哈希。 |
| **审计日志** | 记录谁在什么时候做了什么的日志，包括删除、重置、权限变更和部署操作。 |
| **幂等键** | 防止重复提交产生重复结果的标识。复制考试和延长考试需要它。 |

## 设备与大屏

| 术语 | 含义 |
| --- | --- |
| **实例 ID** | 每台看板设备的唯一标识。同班多台设备要靠它区分。 |
| **心跳** | 设备定时上报状态。超过 3 分钟（180 秒）没有心跳就不再显示为在线。 |
| **绑定** | 把一台设备关联到某个年级和班级。一台设备只绑定一个班级。 |
| **ClassIsland** | 教室端的课表与提醒软件。Novora 插件可在开考前自动打开大屏并提醒。 |
| **配对令牌** | 插件配对时使用的一次性令牌，有效期 5 分钟。 |
| **PWA** | 可安装到桌面的网页应用形式。安装后会缓存应用外壳，短时断网仍能显示已有只读内容。 |
| **Service Worker** | 浏览器端的离线缓存机制。发布新版本时它负责更新缓存。 |

## 部署与运维

| 术语 | 含义 |
| --- | --- |
| **Vercel** | 云端托管平台，负责构建网页并运行 `/api/*` 接口。 |
| **Neon** | 云端 PostgreSQL 数据库服务，云端部署用它保存数据。 |
| **Vercel Functions** | Vercel 上的服务端函数，处理登录、考试、设备等接口请求。 |
| **Deploy Hook** | Vercel 提供的部署钩子。访问它就能触发一次重新构建，用于后端的「一键部署更新」。它只重建当前代码，**不会**拉取新版本。 |
| **Sync fork** | GitHub 上把作者仓库的新提交同步到自己的 Fork。云端更新必须先做这一步。 |
| **Fork** | 把作者仓库复制一份到自己账号下，保留与上游的同步关系。 |
| **环境变量** | 部署配置，例如数据库连接串。只在服务端保存，不出现在浏览器里。 |
| **schema 版本** | 数据库结构的版本号。健康检查会报告当前版本。 |
| **Docker Compose** | 本地部署方式，一条命令同时启动应用和内嵌 PostgreSQL。 |
| **反向代理** | 本地部署中把域名和 HTTPS 流量转发到应用端口的服务，例如 Nginx、Caddy。 |
| **数据卷** | Docker 中持久保存数据库数据的位置。删除容器不丢数据，删除卷才会丢。 |

## 数据与诊断

| 术语 | 含义 |
| --- | --- |
| **遥测** | 上报实例版本、运行环境、匿名实例标识、省份和校名，用于作者了解部署运行情况。不含考试正文。 |
| **诊断日志** | 出现错误时采集的本机日志包。默认只留在设备上，需要管理员手动上传。 |
| **脱敏** | 上报前把敏感内容替换成占位符，例如把连接串、令牌替换为 `<redacted>`。 |
| **投影** | 从权威数据自动生成的一份副本。Novora 用 `exam_records` 投影考试记录，可随时重建，回滚不丢数据。 |
| **归档** | 把已结束的考试从默认列表隐藏，但保留全部历史，可随时反归档。 |
