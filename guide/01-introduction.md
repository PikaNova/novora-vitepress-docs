# 1. 项目介绍

Novora 是一套面向学校教室大屏的考试与周测安排系统。它同时提供学生可见的考试大屏、管理员后台、班级设备绑定、考试安排预览和 A4 PDF 下载。

本教程以 **Novora V2.5.6** 正式版为基准，目标是让没有服务器、数据库和 Git 使用经验的读者，也能从零完成一套可实际使用的部署，并掌握六个管理模块的日常操作。

## 选择部署方式：Vercel 云端 或 本地/内网

Novora 官方支持两种部署方式，先根据学校条件选择其一，再按对应主线继续：

| 对比项 | Vercel 云端（默认） | 本地/内网 |
| --- | --- | --- |
| 托管 | Vercel Functions + Edge | 本机 / 局域网服务器（Docker 或 Node） |
| 数据库 | Neon 云端 PostgreSQL | 内嵌 PostgreSQL 16 或本机 PostgreSQL |
| 公网访问 | 默认支持，可绑定自定义域名 | 内网可直接访问；公网需反向代理 + HTTPS |
| 中国大陆访问 | 境外节点，受运营商影响 | 局域网内稳定；公网依赖自建线路 |
| 成本 | 免费方案即可起步 | 需要一台可长期开机的电脑或服务器 |
| 维护 | 平台自动构建、托管 | 自行备份、更新、监控 |
| 适用场景 | 多校统一管理、无本地硬件 | 教室局域网、无外网、7×24 本地运行 |

**建议**：没有本地硬件或需要公网统一访问时，选择 Vercel 云端，按后续章节部署；需要内网、离线或长期本地运行时，选择[本地/内网部署](/appendix/g-local-deployment)。

本章之后的部署主线按 Vercel 云端讲解；两种方式共用同一份代码，切换部署只需更换数据库连接串。

## 部署完成后有什么

完成本教程后，你会得到：

- 一个使用自定义域名访问的 Novora 网站；
- 一个保存学校、班级、考试和用户数据的 Neon PostgreSQL 数据库；
- 一个可以创建考试、周测和管理用户的后台；
- 一个可绑定到具体班级的教室考试大屏；
- 自动 HTTPS、按 GitHub 提交重新构建的部署流程。

## 主要页面

| 地址 | 用途 | 是否需要登录 |
| --- | --- | --- |
| `/` | 首页、状态概览和班级选择 | 否 |
| `/exam` | 考试大屏和本地临时考试 | 否 |
| `/login` | 管理员登录 | 否 |
| `/admin` | 考试、周测、班级、设备和用户管理 | 是 |
| `/settings` | 系统设置和数据维护 | 是 |
| `/preferences` | 当前班级安排预览和 A4 PDF 下载 | 否 |
| `/local-settings` | 当前设备的班级、显示和字体设置 | 否 |
| `/plugin/connect` | ClassIsland 插件配对 | 配对令牌 |

## 使用的服务

| 服务 | 作用 | 本教程是否必需 |
| --- | --- | --- |
| GitHub | 保存源码，并把源码交给 Vercel | 是 |
| Vercel | 托管网页和 `/api/*` 服务端接口 | 是 |
| Neon | 托管 PostgreSQL 数据库 | 是 |
| 域名服务商 | 提供可自定义的访问地址 | 中国大陆使用时强烈建议 |
| ClassIsland | 在教室端联动考试提醒 | 否 |
| 作者遥测后台 | 集中查看多个部署实例 | 否 |

## 费用说明

GitHub、Vercel 和 Neon 都提供免费方案，适合测试、小规模使用或低访问量场景。免费额度和平台规则可能调整，注册及部署时应以平台当前页面为准。

域名通常需要按年购买。若要使用中国大陆服务器或中国大陆 CDN，还可能涉及云服务器、CDN 和备案费用。

::: warning 不等于中国大陆稳定托管
绑定自定义域名后，网页仍然运行在 Vercel 境外基础设施上。它可能绕开 `vercel.app` 默认域名的访问问题，但无法承诺中国大陆所有地区和运营商稳定访问。正式全校使用前必须用目标学校网络实测。
:::

## 本教程不要求什么

按照 GitHub 导入方式部署时，不需要：

- 自己购买和维护服务器；
- 手工安装 PostgreSQL；
- 在数据库中执行建表 SQL；
- 在电脑上安装 Node.js；
- 会写 React 或 TypeScript。

只有在需要修改源码或本地调试时，才需要阅读[本地开发](/appendix/b-local-development)。
