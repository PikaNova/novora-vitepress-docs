# 6. 批量与导入

后台提供批量应用周测、批量删除计划、批量添加管理员，以及从 JSON 批量导入考试安排等操作，减少重复工作。

## 批量应用周测计划

将一个周测计划批量分配到多个班级，支持搜索、全选与逐个选择。

![批量-应用周测](/pictures/batch-actions-1.png)

## 批量删除周测计划

按年级、班级筛选后勾选计划，一次删除多条周测。

![批量-删除周测](/pictures/batch-actions-2.png)

## 批量添加班级管理员

按年级、班级批量指定班级管理员并生成账号，可导出账号信息。

![批量-添加班级管理员](/pictures/batch-actions-3.png)

## JSON 导入

粘贴 AI 生成的 JSON 考试数据，批量导入考试安排并按时间排序。

![导入-JSON](/pictures/json-import.png)
