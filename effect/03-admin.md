# 3. 后台管理效果

管理后台是管理员完成日常操作的统一入口，包含运行总览、大型考试、周测计划、导出打印、设备管理、用户权限与提醒公告等模块，并按账号授权范围分级展示数据。

## 运行总览

集中展示学校考试概况：当前与下一场考试、周测安排、设备状态等，便于管理员快速掌握全局。

![后台-总览](/pictures/后台-总览.png)

## 大型考试管理

创建、编辑、发布大型考试及分考试，支持批量添加、选科分发与 JSON 导入导出。

![后台-大型考试-管理](/pictures/后台-大型考试-管理.png)

## 周测计划管理

按周历管理周测计划，支持单次取消、临时调课、冲突处理与按班级批量创建计划。

![后台-周测-管理](/pictures/后台-周测-管理.png)

## 导出 PDF

将考试安排导出为 A4 PDF，方便打印张贴或归档。

![后台-导出pdf](/pictures/后台-导出pdf.png)

## 设备管理

管理教室设备绑定、心跳状态与设备角色，可远程切换设备用途。

![后台-设备管理](/pictures/后台-设备管理.png)

## 用户与权限

管理超级管理员、年级管理员、班级管理员与自定义角色，按年级、班级范围授权。

![后台-用户管理](/pictures/后台-用户管理.png)

## 提醒管理

配置考前提醒、公告与显示规则，统一下发到班级大屏。

![后台-提醒管理](/pictures/后台-提醒管理.png)
