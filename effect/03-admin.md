# 3. 后台总览

管理后台的“运行总览”仪表盘，汇总在线设备、待执行大型考试、数据库状态与近期高风险操作，并展示正在进行的考试，帮助管理员快速掌握全校运行情况。

V2.8.0 把导航改到左侧边栏、页面控件集中到顶部上下文栏，并把总览重做为「核心状态卡片 + 运行健康区 + 待办入口」三段式。

页面自上而下是四张核心状态卡（在线设备、待执行大型考试、云端数据状态、最近高风险操作）、
四格运行健康区（数据同步、设备心跳、考试排期、授权范围）、四个常用入口
（统一添加单科考试、数据大屏、大型考试、周测计划），最后是「正在进行」与「最近高风险操作」两个列表。
